## Центральная идея

> **Контроль предполагает возможность заранее получить желаемый результат. Создание происходит независимо от контроля.**

```text
реальная ситуация
→ воспринятая модель
→ состояние
→ автоматическая цепочка
→ образ себя и сценарий
→ доступная точка выбора
→ действие или бездействие
→ последствия
→ обратная связь
→ корректировка
→ следующий цикл
```

## Пять ступеней

```text
1. Жизнь внутри автоматизма

```

## Ступень 3 — активная

### SP-S3-P01

> **Мне уже не обязательно жить из прежнего сценария — но я ещё не знаю, что будет организовывать мои действия вместо него.**

### SP-S3-P02

> **Факт обязателен к учёту, но не диктует единственное продолжение.**

### SP-S3-P03

> **Я не выбирал всё, из чего сформировался, но участвую в том, что формируется дальше.**

### SP-S3-P04

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

### SP-S3-P05

> **Я могу выбрать, для чего будет сделан следующий ход.**

### SP-S3-P06

> **Я выбрал задачу — значит теперь я действую из неё.**

> **Выбор задачи начинает новую линию, но ещё не создаёт устойчивую систему.**

### SP-S3-P07

> **Я действительно выбрал — и всё равно не могу на себя опереться.**

> **Почему мне снова приходится выбирать то, что я уже выбрал?**

> **Неустойчивость выбора не доказывает его нереальность; она показывает, что выбранная линия ещё формируется.**

```text
SP-S1-P07:
мои ходы снова ведут меня не туда

SP-S2-P07:
моё понимание не удерживает меня вне сценария

SP-S3-P07:
мой собственный выбор ещё не становится
надёжной системой, на которую я могу опереться
```

Ключевые границы:

```text
выбор есть ≠ устойчивость уже сформирована
один несогласованный ход ≠ отсутствие сделанного выбора
повторный выбор ≠ возвращение в исходную точку
коррекция задачи по обратной связи ≠ неспособность удерживать выбор
```

## Визуальные модели

Утверждены SP-VM-01 и SP-VM-02. Для P07 граф траектории позволяет видеть изменение даже при наличии откатов; при этом фактическая последовательность ходов не подменяется декларацией задачи.

Новая визуальная модель для P07 не утверждалась.

## Границы

Selection Point не утверждает, что:

- человек создаёт все внешние события;
- мысль, внимание или правильно поставленная задача гарантируют результат;
- существует единственное «настоящее я», которое система может обнаружить;
- внутренняя задача является универсальным скрытым мотивом всех решений;
- один акт выбора задачи мгновенно создаёт устойчивую систему поведения;
- один откат доказывает отсутствие реального выбора;
- необходимость повторно выбирать означает слабость или ненадёжность личности;
- нормальная контекстная вариативность поведения является патологией;
- постоянный сознательный контроль необходим для устойчивости;
- функциональная модель внутренней задачи заменяет профессиональную помощь.
