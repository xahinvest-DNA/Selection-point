## Центральная идея

> **Контроль предполагает возможность заранее получить желаемый результат. Создание происходит независимо от контроля.**

```text
реальная ситуация
→ воспринятая модель
→ состояние
→ доступная точка выбора
→ действие или бездействие
→ последствия
→ обратная связь
→ корректировка
→ следующий цикл
```

## Пять ступеней

```text
1. Жизнь внутри автоматизма
2. Обнаружение повторяющегося сценария
3. Формирование внутренней задачи и устойчивой практики
4. Сохранение выбора под напряжением
5. Создание и адаптация собственной системы
```

## Ступень 3 — активная

### SP-S3-P09 — телесные проявления

> **Меняется не обязательно то, что я чувствую; меняется то, что мне доступно внутри этого состояния.**

### SP-S3-P10 — жизненные проявления

> **Я начинаю последовательно участвовать в том, какую позицию формирую дальше.**

> **Меняется не обязательно вся моя жизнь сразу; меняется то, каким способом я продолжаю её создавать из существующей позиции.**

### SP-S3-P11 — соответствующие практики

Рабочее название:

> **«От наблюдения без обязательной оценки к точному участию».**

Главная формула:

> **Наблюдать без необходимости вмешиваться. Вмешиваться без необходимости постоянно контролировать.**

Дополнительная формула:

> **Устойчивость — не в непрерывном контроле, а в повторяемом возвращении к реальности и участию из неё.**

Функциональный цикл:

```text
текущая внутренняя и внешняя позиция
→ наблюдение без обязательного схлопывания
  в первую оценку
→ различение факта, реакции,
  значения и неизвестного
→ различение необходимости участия
→ действие / пауза / наблюдение /
  отказ / изменение условий
→ интервал без постоянного контроля
→ фактическая следующая позиция
→ возвращение к наблюдению
```

Ключевые границы:

```text
наблюдать без оценки
≠ не испытывать оценок

наблюдение
≠ непрерывная проверка

действие
≠ автоматически лучший ход

практика
= реальный ход
≠ обязательное внешнее изменение

устойчивость
≠ непрерывность контроля
```

P11 определяет функциональные требования к практикам, а не готовые упражнения. Конкретная конструкция практик относится к Фазе 5.

## Визуальные модели

SP-VM-01 и SP-VM-02 связаны с архитектурой до P11 включительно. Новая визуальная модель для P11 не вводилась.

## Границы

Selection Point не утверждает, что:

- сознательно выбранная задача автоматически полезна;
- телесный сигнал является безошибочной истиной или приказом;
- человек создаёт все внешние события;
- внимание или задача гарантируют результат;
- внешняя успешность доказывает более высокую ступень;
- бездействие автоматически является ошибкой;
- конкретная конечная цель обязательна для осмысленного направления;
- «наблюдать без оценки» означает не иметь оценочных мыслей или эмоций;
- нейтральная наблюдательная практика доказанно переносится на все жизненные области;
- наблюдение всегда лучше действия;
- невмешательство всегда является более зрелым ходом;
- устойчивость требует постоянного самоконтроля;
- AI или ведущий вправе определить человеку универсально «правильную» задачу;
- функциональная модель заменяет профессиональную помощь.
