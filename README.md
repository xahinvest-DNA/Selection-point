## Центральная идея

> **Контроль предполагает возможность заранее получить желаемый результат. Создание происходит независимо от контроля.**

```text
реальная ситуация
→ воспринятая модель
→ состояние
→ доступная точка выбора
→ действие или бездействие
→ последствия
→ обратная связь
→ корректировка
→ следующий цикл
```

## Пять ступеней

```text
1. Жизнь внутри автоматизма
2. Обнаружение повторяющегося сценария
3. Формирование внутренней задачи и устойчивой практики
4. Сохранение выбора под напряжением
5. Создание и адаптация собственной системы
```

## Ступень 3 — активная

### SP-S3-P01–SP-S3-P07

Утверждены и сохранены в полном и каноническом слоях.

### SP-S3-P08 — следующий навык

> **Сохранять без упрямства, менять без бегства.**

> **Следующий навык третьей ступени состоит в способности вести сознательно выбранную внутреннюю задачу через повторяющиеся циклы действия и обратной связи: сохранять или восстанавливать её управляющее присутствие, когда основания задачи сохраняются, и уточнять или менять её, когда фактическая следующая позиция даёт существенные основания для пересмотра.**

Формула опоры:

> **Опора на себя — не гарантия, что я не изменю своё решение. Это способность снова участвовать в том, сохранить его или изменить.**

Ключевые различения:

```text
осознанно выбрано ≠ полезно
созидание ≠ улучшение
авторство ≠ мудрость
```

```text
управляющее присутствие задачи
≠ способ решения задачи
≠ сама задача
```

```text
негативный результат одного цикла
≠ автоматическое опровержение задачи

положительный результат одного цикла
≠ доказательство полезности задачи
```

## Визуальные модели

## Границы

Selection Point не утверждает, что:

- сознательно выбранная задача автоматически полезна;
- последовательное достижение цели автоматически означает рост или процветание;
- один успех подтверждает правильность задачи;
- одна неудача опровергает задачу;
- устойчивость означает неизменность решения;
- изменение задачи автоматически означает слабость;
- человек создаёт все внешние события;
- внимание или задача гарантируют результат;
- AI или ведущий вправе определить человеку универсально «правильную» задачу;
- функциональная модель заменяет профессиональную помощь.
