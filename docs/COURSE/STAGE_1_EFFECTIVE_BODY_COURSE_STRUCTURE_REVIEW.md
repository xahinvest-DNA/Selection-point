
# Stage 1 Effective Body Course Structure — Critical Review

**ID:** SP-COURSE-S1-STRUCT-REV-001  
**Date:** 22 September 2026  
**Reviewed:** SP-COURSE-S1-STRUCT-001  
**Result:** revise, preserve five core lessons

## 1. Main finding

The proposed five-lesson count was defensible, but Lesson 1 (“Знание не управляет телом”) was not a distinct Stage 1 operation.

It functioned as orientation.

Keeping it as a full lesson caused a mismatch with the five required practice functions already approved in SP-S1-P11.

## 2. Correct mapping

Foundation requires five practical functions:

1. localize one episode;
2. reconstruct distinguishable links;
3. distinguish the body regulation contour;
4. link action to next position;
5. discover and realize available participation.

The course should teach these through five accumulating operations rather than five conceptual themes.

Revised structure:

~~~text
orientation — why body / knowledge-action gap

lesson 1 — localize one episode
lesson 2 — reconstruct the chain
lesson 3 — state ≠ familiar regulation means
lesson 4 — available participation
lesson 5 — realization → consequence → feedback

integration — preserve several episodes separately
~~~

## 3. Boundary correction: “real need”

The phrase “real need ≠ familiar means” is useful conceptually but can overclaim what a learner objectively knows.

Revised learner-facing form:

> **Состояние ≠ привычный способ его изменить.**

Possible need/function remains a hypothesis.

The teacher must not tell the learner what they “really need.”

## 4. Boundary correction: retrospective availability

The question:

> “What could you really have changed?”

can create retrospective omniscience.

Revised structure separates:

~~~text
what I actually noticed then
what was still open when I noticed it
what can be changed now
what can be changed in the next cycle
~~~

This preserves late entry without pretending that a later imagined alternative was available earlier.

## 5. Boundary correction: Stage 2 leakage

The previous integration ended with:

> “Что в нескольких отдельных эпизодах действительно повторяется?”

That is already the object of Stage 2.

Stage 1 should end with the ability to keep several episodes **separate and comparable**.

Stage 2 begins when the learner actually compares them for recurring functional structure.

## 6. Missing Foundation coverage corrected

The revised Lesson 4 now explicitly includes all four SP-S1-P11 practice classes:

- retrospective reconstruction;
- return inside ongoing continuation;
- repair/recovery after episode;
- change one condition of next cycle.

This prevents the course from defining successful participation only as “stop before the lapse.”

## 7. Instructional-design review

The course anatomy should not be pure lecture.

For novice skill acquisition, worked examples can reduce unnecessary cognitive load, especially before independent problem-solving/application.

Self-application remains necessary so the learner does not merely repeat teacher language.

Distributed practice supports retention in learning research, but does not determine an exact SP course calendar.

Structured debriefing has meta-analytic support as a learning/performance tool across multiple training domains.

Therefore the revised lesson anatomy is:

~~~text
debrief prior reality
→ worked example
→ one explicit distinction
→ guided learner application
→ field task
→ next debrief
~~~

## 8. Timeframe correction

A fixed 7–14 day course was too crisp for a skill whose raw material is naturally occurring episodes.

Revised first-pilot hypothesis:

> **roughly 7–21 days, event-informed rather than rigidly calendar-gated.**

This remains a delivery hypothesis only.

## 9. Verdict

Retain **five core lessons**, but use revised SP-COURSE-S1-STRUCT-002.

Do not write Lesson 1 until Owner reviews this revised architecture.
