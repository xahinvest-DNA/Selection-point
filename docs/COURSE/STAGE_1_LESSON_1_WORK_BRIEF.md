## 1. Methodological core retained

Lesson 1 still centers on one operational move:

> **Replace a global conclusion about the person or their life with one bounded, reality-anchored episode that can actually be examined.**

Compact form:

```text
global label / vague problem
→ one concrete episode
→ minimum factual description
→ current position becomes more distinguishable
```

The lesson must still stop before:

- full causal reconstruction;
- hidden-cause search;
- repeating-pattern analysis;
- alternative-regulation teaching;
- complete Selection Point cycle;
- Stage 2 pattern work.

## 2. Minimum episode content retained as candidate input

The previously approved five fields remain useful candidates, not yet final online-course UI/content requirements:

1. what happened;
2. when / where;
3. relevant factual conditions, only where needed;
4. realized action / inaction;
5. immediate observable result.

Unknown remains valid. Late noticing remains valid. Successful and unsuccessful episodes are both admissible when relevant to the chosen body direction.

## 3. What is reopened

The following parts of the previous brief are no longer approved delivery mechanics:

- seven-phase teacher-led flow;
- teacher/AI guided application;
- live one-question-at-a-time questioning;
- teacher-led adaptive branches;
- live present-action bridge;
- any requirement for a facilitator to separate fact from interpretation in real time.

These must be redesigned for independent learner use.

## 4. Product-format constraint

The course is a **self-paced online course**.

Each lesson must work without a teacher or required AI assistant and should combine:

```text
theoretical material
+
independent practical work
+
field application in ordinary life
+
learner-visible result / artifact
```

The course may later use software or optional support, but the core lesson cannot depend on it.

## 5. Next dependency

Do not write Lesson 1 again until the reusable self-paced lesson anatomy is discussed and approved at the template level.

The Lesson 1 methodological boundary remains available as input to that redesign.
