## 1. Reason for reopening

The v2 template was built around the assumption:

```text
Teacher/AI holds the structure
→ learner answers
→ guided dialogue
```

That assumption is incorrect for the intended product.

The intended product format is:

```text
SELF-PACED ONLINE COURSE
=
theoretical material
+
independent practical work by the learner
+
reality feedback between lessons
```

There is no required teacher, facilitator or AI assistant in the delivery loop.

Therefore the following parts of the old v2 mechanics are **not controlling** and must be redesigned before Lesson 1 is written again:

- teacher/AI modes;
- one-question-at-a-time guided dialogue;
- teacher-led debrief;
- teacher-led adaptive branches;
- “teacher/AI + learner” manual delivery;
- any dependency on a live interlocutor to keep the learner inside the lesson boundary.

## 2. What remains valid as methodological input

The reopening does **not** reject the approved Stage 1 course structure or its methodological boundaries.

Retain as working inputs for the redesign:

- one main learning operation per lesson;
- created direction + factual current position;
- direction ≠ route ≠ next step ≠ realized action;
- reality-coupled practice;
- one bounded field task rather than global self-monitoring;
- unknown is valid;
- late noticing is valid;
- questionnaire remains separate longitudinal telemetry;
- attention should not be permanently centered on the weakest behavior;
- safety boundaries remain mandatory;
- Stage 2 pattern analysis must not leak into Stage 1 lessons.

These are methodological constraints, not a finished online lesson format.

## 3. Redesign task

Before any new Lesson 1 artifact is written, define and approve the stable anatomy of one **self-paced online lesson**.

At minimum the redesign must answer:

1. What theoretical material does the learner receive?
2. How is a new distinction explained without a live teacher?
3. What practical task is performed inside the lesson?
4. What practical task is performed in ordinary life after the lesson?
5. How does the learner check their own work without requiring a teacher/AI?
6. What minimum artifact/result does the learner retain?
7. How is overload avoided?
8. How does the next lesson use the result of the previous one?
9. What safety and uncertainty instructions must be embedded directly in the material?
10. Which previous v2 mechanics should be retained, transformed or removed?

## 4. Scope boundary

This reopening does not authorize:

- Lesson 2 development;
- Stage 2;
- Foundation S5;
- external pilot;
- trainer implementation;
- questionnaire redesign.

The next task is the self-paced lesson architecture itself.
