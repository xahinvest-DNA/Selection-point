# DECISIONS

**Статус:** индекс прежних продуктовых решений и действующих governance-решений.  
**Текущий архитектурный статус:** `FOUNDATION/PROJECT_STATE.yaml`  
**Действующий методологический смысл:** `FOUNDATION/`.

Этот файл не является самостоятельным журналом текущего состояния.

## Иерархия

При расхождении приоритет имеют:

1. последнее явное решение Андрея;
2. `docs/FOUNDATION/PROJECT_STATE.yaml` — только для текущего статуса;
3. `docs/FOUNDATION/PROJECT_OPERATING_PROTOCOL.md` и governance-документы — для процесса;
4. `docs/FOUNDATION/ARCHITECTURAL_DECLARATION.md` и `HUMAN_CHANGE_MODEL.md`;
5. полный утверждённый теоретический слой;
6. канонический слой;
7. библиотеки и производные статусы;
8. legacy-решения ниже.

## Действующая общая модель

```text
реальная ситуация
→ воспринятая модель ситуации
→ текущее состояние
→ автоматическая цепочка
→ образ себя и внутренний сценарий
→ доступная точка выбора
→ действие или бездействие
→ внешние и внутренние последствия
→ обратная связь
→ системная корректировка
→ следующий цикл из изменённой позиции
```

## Текущий процесс

```text
3 вопроса
→ обсуждение
→ Architect pass
→ Reality Check
→ Red Team / Falsification
→ явное решение Андрея
→ full theory
→ canonical
→ parameter delta
→ PROJECT_STATE.yaml
→ производные статусы
→ checkpoint
→ consistency check
```

Ни одно прежнее решение о курсе, длительности, приложении или техническом стеке не становится действующим без нового явного утверждения на соответствующей фазе.
