## Действующая общая модель

Foundation-модель сохраняется:

```text
реальная ситуация
→ воспринятая модель ситуации
→ текущее состояние
→ автоматическая цепочка
→ образ себя и внутренний сценарий
→ доступная точка выбора
→ действие или бездействие
→ внешние и внутренние последствия
→ обратная связь
→ системная корректировка
→ следующий цикл из изменённой позиции
```

Environment-first route не отменяет эту модель, а переводит её в правила и state transitions среды.

## Текущий продуктовый процесс

```text
owner-approved direction
→ one target capability
→ representative scenario grammar
→ 10–15 bounded scenarios
→ manual/simplest possible simulation
→ one real-world transfer experiment
→ evidence / contradictions
→ owner review
→ only then next route decision
```

Принцип защиты от повторения предыдущей ошибки:

> Новый интересный вывод не даёт автоматического права расширить V0. Если он не нужен для проверки одного утверждённого механизма, он остаётся кандидатом для следующей версии.
