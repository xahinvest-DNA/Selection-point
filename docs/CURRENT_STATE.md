```text

→ прежняя форма продолжения может измениться

→ новый practically available ход
→ несколько следующих ходов
```

При этом:

```text
сохранение направления ≠ persistence любой ценой
изменение формы ≠ зрелость само по себе
хороший исход ≠ критерий P10
скорость восстановления ≠ критерий P10
```
