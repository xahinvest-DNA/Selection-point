## Ступень 3 — утверждённые параметры

### SP-S3-P01 — состояние человека

> **Мне уже не обязательно жить из прежнего сценария — но я ещё не знаю, что будет организовывать мои действия вместо него.**

> **Внутренний голос имеет рекомендательный характер. Услышать рекомендацию — ещё не значит принять решение.**

### SP-S3-P02 — способ восприятия реальности

> **То, что есть сейчас, — факт. Что из этого возможно дальше, заранее известно не полностью.**

> **Факт обязателен к учёту, но не диктует единственное продолжение.**

### SP-S3-P03 — способ восприятия себя

> **То, какой я сейчас, — факт моей текущей позиции, но не окончательный ответ на вопрос, кем я могу стать.**

> **Я не обязан сначала найти «настоящего себя», чтобы начать участвовать в том, кем становлюсь.**

> **Я не выбирал всё, из чего сформировался, но участвую в том, что формируется дальше.**

### SP-S3-P04 — что управляет решениями

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

> **Заявленная цель говорит, чего я хочу. Внутренняя задача проявляется в том, что реально начинает организовывать мои решения.**

> **Свобода становится созидательной, когда человек способен не только отказаться от автоматической задачи, но и принять задачу, которая начинает организовывать его следующие ходы.**

```text
оперативная задача
→ текущий эпизод

сценарная задача
→ повторяющиеся эпизоды

созидательная внутренняя задача
→ несколько сознательно организованных следующих циклов
```

Основной контур:

```text
текущая позиция + состояние + модели + внешний контекст
→ активная внутренняя задача
→ внимание
→ значимые данные
→ интерпретация
→ поле ходов
→ решение
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ обновление моделей и условий следующего цикла
```

Ключевые границы:

```text
заявленная цель ≠ фактически действующая задача
убеждение ≠ внутренняя задача
желание ≠ автоматически принятая задача
правильная организация выбора ≠ гарантированный результат
```

Термин «метапрограмма» не канонизирован.
