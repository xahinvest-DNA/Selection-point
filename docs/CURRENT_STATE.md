## Открытая третья ступень

### SP-S3-P01 — состояние человека

> **Мне уже не обязательно жить из прежнего сценария — но я ещё не знаю, что будет организовывать мои действия вместо него.**

Переходное различение:

> **Внутренний голос имеет рекомендательный характер. Услышать рекомендацию — ещё не значит принять решение.**

### SP-S3-P02 — способ восприятия реальности

> **На третьей ступени реальность постепенно перестаёт восприниматься как готовое описание того, кто человек, что с ним происходит и каким должно быть продолжение. Текущая позиция признаётся фактом со своими реальными условиями, ограничениями, ресурсами и последствиями, но этот факт не содержит автоматически единственного значения и единственного следующего хода.**

Короткая формула:

> **То, что есть сейчас, — факт. Что из этого возможно дальше, заранее известно не полностью.**

Операционная формула:

> **Факт обязателен к учёту, но не диктует единственное продолжение.**

```text
текущая фактическая позиция
→ интерпретация
→ различение факта и модели
→ часть неизвестного остаётся открытой
→ доступный ход
→ независимый ответ среды
→ фактическая следующая позиция
→ корректировка модели
```

Ключевые границы:

```text
создание
≠ магический контроль

влияние
≠ гарантия

не знаю
≠ ничего нельзя сделать

не знаю
≠ всё возможно
```

Действие начинает рассматриваться как:

```text
действие
= воздействие
+ исследование
```
