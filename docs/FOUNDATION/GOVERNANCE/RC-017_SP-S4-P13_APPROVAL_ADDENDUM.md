# RC-017 — Approval Addendum для SP-S4-P13

**Дата:** 5 сентября 2026 года  
**Объект:** SP-S4-P13 — «Ловушка четвёртой ступени»  
**Статус:** owner-approved; cycle closed

## 1. Явное решение владельца

После первоначального Architect / RC-017 / Red Team, последующего уточнения механизма через временной масштаб, полного повторного Architect pass, revised Reality Check и revised Red Team Андрей принял решение:

> **«Утверждаем».**

## 2. Утверждённый центральный тезис

> **Ловушка четвёртой ступени возникает, когда полезная способность возвращаться к доступному выбору в каждом отдельном моменте непреднамеренно превращает moment-level view в основной и почти единственный масштаб оценки. Тогда серия функционально сходных эпизодов может не получить достаточного веса как новая фактическая позиция.**

Главная формула:

> **Выбор совершается в моменте. Траектория обнаруживается во времени.**

Корректирующая формула:

> **Прошлое не должно определять следующий выбор, но релевантная история должна иметь право изменить описание текущей позиции.**

## 3. Обязательные ограничения

```text
present moment ≠ trap
history = data ≠ verdict / identity / destiny
single lapse ≠ trajectory
series ≠ proof of single cause
bad outcomes ≠ bad process
macro review ≠ total self-monitoring
aggregation ≠ guilt scoreboard
```

## 4. Дельта относительно P12

```text
P12:
право на re-entry после отдельного выпадения

P13:
право на re-entry
≠ право обнулить accumulated series-level feedback
```

## 5. Внешний статус

RC-017 обнаружил совместимость отдельных компонентов с:

- lapse / relapse distinction;
- behaviour-maintenance literature;
- EMA distinction between moment-level and unfolding processes;
- context-dependent relapse / habit research.

Эти данные не доказывают пятиступенчатую архитектуру Selection Point.

Статусы:

- `owner-approved`;
- `externally-compatible` по отдельным компонентам;
- `externally-limited`;
- `pilot-observability-pending`;
- `falsifier-defined`.

## 6. Falsifier

P13 должен быть пересмотрен, если в пилоте / дальнейшей архитектуре его нельзя отличить от общего review, если временной масштаб неизбежно выбирается post hoc, если aggregation создаёт outcome bias / hyper-monitoring или если P12 уже полностью покрывает practically useful distinction.
