# RC-018 — Approval Addendum

**Дата:** 15 сентября 2026 года  
**Объект:** cross-cutting boundary `choice → realized continuation → consequences → feedback`  
**Статус:** owner-approved; cycle closed

## 1. Явное решение владельца

После Architect pass, RC-018 Reality Check и Red Team Андрей принял решение:

> **«Утверждаем».**

## 2. Утверждённое различение

> **Selection Point должен явно различать внутренне выбранное продолжение и фактически реализованное продолжение.**

```text
выбранное продолжение
≠ фактически реализованное продолжение
≠ последствия
≠ использованная обратная связь
```

Короткая формула:

> **Выбрать ≠ сделать. Сделать ≠ получить желаемое. Последствия ≠ автоматически использованная обратная связь.**

## 3. Что считается фактически реализованным продолжением

Это то, что реально произошло и вошло в причинную историю следующей позиции. Оно может быть:

- совершённым действием;
- частичным исполнением;
- сознательно выдержанной паузой / отказом / невмешательством;
- автоматическим действием, отличным от выбранного;
- фактическим неисполнением выбранного действия;
- сознательным пересмотром решения после появления новых фактов.

## 4. Главное следствие

> **Неисполненный выбор нельзя засчитывать как совершённый ход и нельзя приписывать ему внешнюю обратную связь как будто соответствующее действие произошло.**

Если человек выбрал X, но X не реализовал, реальность может дать данные:

- о самом внутреннем выборе;
- о разрыве `выбор → реализация`;
- о фактически произошедшем продолжении;
- о его последствиях.

Но она не дала ответ на внешнее действие X, которого не было.

## 5. Обязательные границы

```text
internal choice = real event
≠ proof of execution

selected ≠ realized
≠ automatically sabotage / weakness / moral failure

conscious non-action
may be realized continuation

partial execution
→ only partial test

action
≠ guaranteed desired outcome
≠ guaranteed clear causal feedback

consequences
≠ automatically used feedback
```

## 6. Архитектурный статус

RC-018 утверждён как **cross-cutting clarification / boundary**, а не как новый психологический механизм и не как SP-HCM-10.

Он уточняет уже утверждённые:

- Architectural Declaration;
- SP-HCM-05 — действие создаёт контакт с реальностью и новый опыт;
- SP-HCM-06 — последствия не равны использованной обратной связи;
- SP-HCM-07 — выбор может восстанавливаться на разных участках цепочки;
- SP-HCM-08 — изменение строится повторяемыми циклами;
- SP-S4-P13 — траектория обнаруживается во времени;
- Protocol v4.1 — `выбрать → действовать → дать реальности ответить → получить факт`.

## 7. Связь с траекторией

> **Внутренние выборы показывают направление намерения; фактически реализованные продолжения участвуют в построении фактической траектории.**

Следовательно:

```text
серия выбранных ходов
≠ автоматически серия реализованных ходов
```

Разрыв между ними является самостоятельными данными и должен иметь право изменить описание текущей позиции.
