## Утверждённый результат

> **На четвёртой ступени тело остаётся значимой частью фактической текущей позиции и может участвовать в изменении состояния и доступности действия, но отдельный новый класс телесных проявлений S4 не подтверждён.**

Коротко:

> **Тело не только показывает позицию — оно участвует в её изменении. Но это не отдельная S4-дельта.**

## Сохранённая сквозная граница

```text
тело
=
часть текущей позиции
+
может быть причинным участником дальнейшей динамики состояния
```

Но:

```text
body-state bidirectionality
≠ unique S4 mechanism
```

## Обязательные предохранители

```text
телесный сигнал = данные
≠ только данные
```

```text
изменение тела может влиять на состояние
≠ гарантирует изменение состояния
```

```text
улучшение состояния
≠ восстановление выбора
```

```text
сильная активация
≠ потеря выбора
```

```text
спокойствие
≠ доказательство выбора
```

```text
конкретный телесный показатель
≠ универсальный биомаркер выбора
```

## P09 / P11 boundary

Намеренное использование телесного компонента текущей позиции как возможного входа для изменения состояния / practically available участия сохраняется как кандидат функционального класса SP-S4-P11.

Это не превращает улыбку, позу, дыхание, движение, visualization или иные техники в утверждённые универсальные практики.
