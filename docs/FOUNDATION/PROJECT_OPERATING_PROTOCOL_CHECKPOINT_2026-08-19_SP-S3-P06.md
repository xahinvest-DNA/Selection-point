## 3. SP-S3-P06 — утверждённое положение

Полный источник:

- `docs/FOUNDATION/FIVE_STAGES_THEORY/32_STAGE_3_MAIN_ILLUSION.md`.

Канонический источник:

- `docs/FOUNDATION/CANONICAL/24_STAGE_3_P06_CANONICAL.md`.

Рабочее название:

> **«Я выбрал задачу — значит теперь я действую из неё».**

Центральный тезис:

> **Главная иллюзия третьей ступени состоит в том, что человек принимает сознательный выбор внутренней задачи за уже сформированную устойчивую организацию поведения: если задача действительно выбрана, она будто должна автоматически определять дальнейшие решения. Но выбор задачи лишь вводит новый организующий фактор в последующие циклы; его реальное управляющее присутствие формируется, проверяется и корректируется через действия, обратную связь и повторение.**

Главная формула иллюзии:

> **Я выбрал задачу — значит теперь я действую из неё.**

Корректирующие формулы:

> **Выбор задачи начинает новую линию, но ещё не создаёт устойчивую систему.**

> **Выбрать задачу — не значит закончить выбирать.**

> **Выбор запускает формирование, но не является самим сформированным результатом.**

---

## 4. Дельта трёх ступеней

```text
SP-S1-P06:
текущая сборка = необходимость

SP-S2-P06:
противоположность старому = собственное направление

SP-S3-P06:
выбор задачи = сформированный организатор
```

P06 не пересматривает P05. P05 определяет возможность изменить задачу-организатор; P06 запрещает считать один акт такого выбора уже завершённым формированием устойчивой системы поведения.

---

## 5. Центральное различение

```text
задача сознательно выбрана
≠
задача получила устойчивый управляющий приоритет
```

Дополнительные границы:

```text
один согласованный ход
≠ устойчивая система

один несогласованный ход
≠ отсутствие сделанного выбора

устойчивая организация
≠ постоянное сознательное удержание формулировки

правильная организация участия
≠ гарантированный внешний результат
```

---

## 6. Причинный контур формирования

```text
сознательный выбор задачи
→ новый организующий фактор
→ следующий доступный ход
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ обратная связь
→ повторное участие
→ повторение / корректировка
→ изменение навыков, ожиданий,
  моделей и доступности ходов
→ постепенное изменение
  системы будущих решений
```

Это связывает P06 со SP-HCM-08: новая конфигурация формируется повторяющимися циклами, а не единичным решением.

---

## 7. Выбор не отменяет следующих точек выбора

Утверждённая формула:

> **Выбрать задачу — не значит закончить выбирать.**

Следующий цикл может происходить в другом состоянии, при новых данных, внешнем давлении, конкурирующих задачах и иной психологической доступности действий.

Поэтому выбранная задача не обязана автоматически вести человека сама.

---

## 8. Устойчивость не равна тотальному самоконтролю

P06 не должен читаться как требование каждую секунду сознательно удерживать задачу.

```text
если задача не управляет автоматически
≠
я обязан постоянно контролировать
каждую мысль, импульс и действие
```

Повторяющиеся циклы могут постепенно делать новую организацию менее зависимой от постоянного сознательного усилия.

---

## 9. Связь с SP-SRC-001

Для P06 приоритетный первичный источник уточняется границей:

```text
принятая задача / модель
→ может организовать внимание и следующий ход

но

один акт принятия
≠ устойчивая новая система решений
```

Формирование продолжается через реальные действия, ответ среды, следующую позицию, обратную связь и изменение условий будущего выбора.

Это остаётся причинной, а не магической трактовкой.

## 12. Доказательный статус

SP-S3-P06 утверждён как положение внутренней архитектуры Selection Point.

Требуется внешняя проверка по темам:

- intention–behavior gap;
- goal commitment;
- goal pursuit;
- implementation intentions;
- habit formation;
- self-regulation;
- action control;
- cognitive control;
- motivational conflict;
- relapse and lapse processes;
- skill acquisition;
- automaticity;
- feedback learning.

Главная проверяемая граница:

```text
сознательное принятие задачи
может причинно влиять на поведение

≠
один акт выбора мгновенно создаёт
устойчивую систему решений
```

Внутренняя утверждённость не является научной или клинической доказанностью.
