## Центральный тезис

> **Следующий навык третьей ступени состоит в способности вести сознательно выбранную внутреннюю задачу через повторяющиеся циклы действия и обратной связи: сохранять или восстанавливать её управляющее присутствие, когда основания задачи сохраняются, и уточнять или менять её, когда фактическая следующая позиция даёт существенные основания для пересмотра.**

Короткая формула:

> **Сохранять без упрямства, менять без бегства.**

Формула опоры на себя:

> **Опора на себя — не гарантия, что я не изменю своё решение. Это способность снова участвовать в том, сохранить его или изменить.**

Дополнительная граница:

> **Не терять выбранное направление без причины и не держаться за него вопреки реальности.**

## Обязательное различение из SP-SRC-002

```text
осознанно выбрано
≠ полезно

созидание
≠ улучшение

авторство
≠ мудрость
```

Сама сознательно выбранная задача остаётся открытой проверке фактическими последствиями и обратной связью.

## Три уровня различения

Фактическая следующая позиция используется для различения:

1. **управляющего присутствия задачи** — задача остаётся обоснованной, но потеряла приоритет;
2. **способа решения задачи** — задача сохраняется, но способ требует изменения;
3. **самой задачи** — накопленные данные дают существенные основания для уточнения или замены задачи.

```text
задача B
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ обратная связь

→ B остаётся обоснованной и сохраняет приоритет
  → продолжить

→ B остаётся обоснованной, но потеряла приоритет
  → восстановить B в следующем доступном ходе

→ B остаётся обоснованной, но способ не работает
  → изменить способ

→ накопленные данные подрывают основания B
  → уточнить или изменить B
```

## Дельта трёх ступеней

```text
SP-S1-P08:
реконструировать конкретный автоматический эпизод

SP-S2-P08:
использовать фактическую следующую позицию
как обратную связь о сценарной организации

SP-S3-P08:
использовать повторяющиеся реальные циклы,
чтобы сохранять, восстанавливать
или пересматривать
сознательно выбранную задачу
```

## Уточнение устойчивости

> **Устойчивость — способность сохранять выбранную организацию достаточно долго, чтобы получить реальную обратную связь, и одновременно оставаться способным изменить её, когда накопленные данные дают основания для пересмотра.**

```text
слишком быстро менять задачу
→ она не проходит реальную проверку

никогда не менять задачу
→ обратная связь перестаёт иметь значение
```

Числовой или процедурный критерий «достаточно долго» P08 не задаёт.

## Центральные границы

```text
обратная связь
= данные для следующего выбора
≠ внешний приказ
```

```text
негативный результат одного цикла
≠ автоматическое опровержение задачи
```

```text
положительный результат одного цикла
≠ доказательство полезности задачи
```

```text
изменить способ
≠ обязательно изменить задачу
```

```text
изменить задачу по достаточной обратной связи
≠ потерять авторство
```

## Что P08 не утверждает

- Selection Point не знает универсально полезную цель для человека;
- неизменность решения не является критерием зрелости;
- любой дискомфорт или неудача не требуют смены задачи;
- любой успех не подтверждает полезность задачи;
- максимизация количества будущих вариантов не является универсальным благом;
- устойчивость не требует постоянного сознательного контроля;
- AI, ведущий или система не вправе определить человеку его «правильную» задачу;
- функциональная корректировка задачи не заменяет профессиональную помощь в клинических или медицинских состояниях.

Нового общего термина, общего риска и визуальной модели SP-S3-P08 не вводит.

## Доказательный статус

SP-S3-P08 утверждён как положение внутренней архитектуры Selection Point и требует внешней проверки по темам goal adjustment, goal disengagement/reengagement, adaptive persistence, psychological flexibility, feedback processing, self-regulation, error-based learning, escalation of commitment, decision-making under uncertainty и смежным направлениям.

Внутренняя утверждённость не равна научной или клинической доказанности.
