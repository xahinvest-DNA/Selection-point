# Канонический слой Selection Point

**Статус:** действующий производный слой утверждённой архитектуры  
**Дата создания:** 4 июля 2026 года  
**Дата обновления:** 18 августа 2026 года

Канонический слой хранит компактную структурированную форму утверждённых положений. Он создаётся из полного теоретического слоя и используется для навигации, проверки целостности и проектирования следующих фаз.

## Главное различие

```text
полный теоретический слой
= весь разбор, аргументация, примеры, исключения и путь к решению

канонический слой
= утверждённая архитектура в компактной форме

библиотеки
= повторно используемые термины, тезисы, примеры, риски и связи

материалы доставки
= будущий курс, практики, пилот, AI и продукт
```

Правила слоя:

- `00_CANONICAL_RULES.md`.

### SP-S3-P01 — состояние человека

**Рабочее название:** «Сценарий уже не обязан определять следующий ход, собственная линия ещё не сформирована».

> **Мне уже не обязательно жить из прежнего сценария — но я ещё не знаю, что будет организовывать мои действия вместо него.**

Переходное различение:

> **Внутренний голос имеет рекомендательный характер. Услышать рекомендацию — ещё не значит принять решение.**

Полный источник:

- `../FIVE_STAGES_THEORY/27_STAGE_3_STATE.md`.

### SP-S3-P02 — способ восприятия реальности

**Рабочее название:** «Факт обязателен к учёту, но не диктует единственное продолжение».

> **То, что есть сейчас, — факт. Что из этого возможно дальше, заранее известно не полностью.**

> **Факт обязателен к учёту, но не диктует единственное продолжение.**

Основной механизм:

```text
текущая фактическая позиция
→ интерпретация
→ различение факта и модели
→ неизвестное остаётся открытым там, где данных нет
→ доступный ход
→ независимый ответ среды
→ фактическая следующая позиция
→ корректировка модели
```

Ключевые границы:

```text
не знаю
≠ ничего нельзя сделать

не знаю
≠ всё возможно

создание
≠ магический контроль

влияние
≠ гарантия
```

Полный источник:

- `../FIVE_STAGES_THEORY/28_STAGE_3_REALITY_PERCEPTION.md`.
