## Активный SP-S4-P05

Три вопроса предварительной рефлексии завершены, после чего по явному решению владельца открыт **полный Architect pass**.

Никакая рабочая формулировка P05 пока не является каноном.

В частности, гипотеза о том, что Selection Point может описывать «вновь возникающую доступность участия в следующем ходе из фактической текущей позиции», должна пройти самостоятельную архитектурную проверку, Reality Check и Red Team. Допустим `zero-delta`.

---

## Reality Check и falsification

Новая каноническая карточка создаётся только после:

```text
Architect pass
→ Reality Check
→ Red Team / Falsification
→ обсуждение
→ явное утверждение Андрея
```

Для активного P05 действует `../GOVERNANCE/RC-009_SP-S4-P05.md`.
