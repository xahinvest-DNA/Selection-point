## Центральный тезис

> **Внутренне выбранное продолжение не равно фактически реализованному продолжению.**

```text
selected continuation
≠ realized continuation
≠ consequences
≠ used feedback
```

Коротко:

> **Выбрать ≠ сделать. Сделать ≠ получить желаемое. Последствия ≠ автоматически использованная обратная связь.**

## Core cycle

```text
фактическая позиция
→ доступная точка выбора
→ выбранное продолжение
→ фактически реализованное продолжение
→ последствия
→ замеченные / интерпретированные данные
→ обратная связь
→ корректировка
→ следующая фактическая позиция
```

## Обязательные различения

- внутренний выбор является реальным событием, но не доказательством исполнения;
- неисполненный ход не получает внешней проверки как будто он произошёл;
- сознательная пауза, отказ или невмешательство могут быть реализованным продолжением;
- частичное исполнение даёт только частичную проверку;
- несовпадение `selected vs realized` является данными, а не автоматическим доказательством саботажа или слабой воли;
- совершённое действие не гарантирует желаемого результата или однозначного causal feedback;
- последствия становятся использованной обратной связью только через их включение в корректировку следующего цикла.

## Связь с P13

> **Внутренние выборы показывают направление намерения; фактически реализованные продолжения участвуют в построении фактической траектории.**

P13 остаётся неизменным:

> **Выбор совершается в моменте. Траектория обнаруживается во времени.**

RC-018 уточняет, из каких наблюдаемых событий эта траектория складывается.
