# SP-S3-P06 — Главная иллюзия третьей ступени

**Статус:** утверждено  
**Дата утверждения:** 19 августа 2026 года  
**Рабочее название:** «Я выбрал задачу — значит теперь я действую из неё»  
**Полный источник:** `docs/FOUNDATION/FIVE_STAGES_THEORY/32_STAGE_3_MAIN_ILLUSION.md`

## Один вопрос параметра

> **Какую ошибку человек начинает совершать после того, как реально обнаружил способность выбирать задачу-организатор следующего хода?**

## Центральный тезис

> **Главная иллюзия третьей ступени состоит в том, что человек принимает сознательный выбор внутренней задачи за уже сформированную устойчивую организацию поведения: если задача действительно выбрана, она будто должна автоматически определять дальнейшие решения. Но выбор задачи лишь вводит новый организующий фактор в последующие циклы; его реальное управляющее присутствие формируется, проверяется и корректируется через действия, обратную связь и повторение.**

Главная формула иллюзии:

> **Я выбрал задачу — значит теперь я действую из неё.**

Корректирующие формулы:

> **Выбор задачи начинает новую линию, но ещё не создаёт устойчивую систему.**

> **Выбрать задачу — не значит закончить выбирать.**

> **Выбор запускает формирование, но не является самим сформированным результатом.**

## Центральное различение

```text
задача сознательно выбрана
≠
задача получила устойчивый управляющий приоритет
```

```text
я выбрал
≠
я уже изменился как устойчивая система решений
```

## Дельта трёх ступеней

```text
SP-S1-P06:
текущая сборка = необходимость

SP-S2-P06:
противоположность старому = собственное направление

SP-S3-P06:
выбор задачи = сформированный организатор
```

В человеческом языке:

```text
SP-S1-P06:
«То, что сейчас кажется необходимым,
и есть единственно возможное продолжение».

SP-S2-P06:
«Раз я двигаюсь прочь от старого,
значит я уже двигаюсь к своему».

SP-S3-P06:
«Раз я сознательно выбрал свою задачу,
значит она уже стала системой,
из которой я действую».
```

## Основной механизм

```text
прежняя задача становится различимой
→ SP-S3-P05
→ человек сознательно принимает задачу B
→ возникает реальное переживание авторства
→ скрытый скачок:
  «значит теперь B управляет мной»
→ ожидание автоматической согласованности
→ состояние, прежние модели,
  внешнее давление и другие задачи
  снова участвуют в решении
→ обнаруживается расхождение
```

P06 заканчивается на ошибочном ожидании автоматической сформированности. Переживание расхождения относится к SP-S3-P07 и здесь не определяется.

## Выбор задачи и формирование системы

```text
сознательный выбор задачи
→ новый организующий фактор
→ следующий доступный ход
→ действие / бездействие
→ ответ среды
→ следующая позиция
→ обратная связь
→ повторное участие
→ повторение / корректировка
→ изменение навыков, ожиданий,
  моделей и доступности ходов
→ постепенное изменение
  системы будущих решений
```

> **Один акт выбора может изменить следующий цикл, но не обязан мгновенно перестроить всю систему, из которой возникают решения.**

## Выбор не отменяет следующих точек выбора

```text
я выбрал задачу
≠
задача теперь должна вести меня сама
```

В следующих циклах могут измениться состояние, данные, давление среды, конкурирующие задачи и фактическая обоснованность прежнего решения.

> **Выбранная задача не отменяет следующие точки выбора.**

## Устойчивость не равна постоянному сознательному контролю

Исправление иллюзии не требует тотального внутреннего надзора.

```text
устойчивая организация
≠ постоянное сознательное удержание формулировки
```

Повторение может постепенно изменять навыки, ожидания и привычные приоритеты так, что новая организация требует меньше сознательного усилия.

## Один откат не отменяет сделанный выбор

```text
один согласованный ход
≠ устойчивая система

один несогласованный ход
≠ отсутствие сделанного выбора
```

Несогласованный ход является данными о текущей организации, а не автоматическим доказательством того, что предыдущий выбор был ложным.

## Результат

```text
правильная организация участия
≠ гарантированный внешний результат
```

Даже устойчиво действующая задача не контролирует другого человека, рынок, организм, случайность и внешнюю среду полностью.

## Что не считается иллюзией автоматически

- ясное сознательное решение;
- высокая приверженность задаче;
- планирование последовательности действий;
- временное сознательное удержание задачи;
- использование внешних опор;
- повторение, повышающее устойчивость;
- корректировка или отказ от задачи после новой обратной связи.

Иллюзия начинается там, где **акт выбора принимается за уже сформированную способность или устойчивую систему решений**.

## Применимые границы

Особенно значимы SP-RISK-001, SP-RISK-002, SP-RISK-005, SP-RISK-007, SP-RISK-008, SP-RISK-010, SP-RISK-014, SP-RISK-016, SP-RISK-019, SP-RISK-020, SP-RISK-023 и SP-RISK-025.

Нельзя утверждать, что:

- если задача действительно выбрана, человек обязан действовать из неё без отклонений;
- несогласованный ход доказывает отсутствие реального выбора;
- один волевой акт мгновенно перестраивает все мотивационные процессы;
- человек обязан постоянно держать задачу в сознании;
- правильно выбранная задача гарантирует внешний результат;
- зависимость, травма или иное клиническое состояние преодолеваются одной сменой задачи.

Нового общего риска и нового термина параметр не вводит.

## Доказательный статус

SP-S3-P06 является утверждённым положением внутренней архитектуры Selection Point.

Требуется внешняя проверка по intention–behavior gap, goal commitment, goal pursuit, implementation intentions, habit formation, self-regulation, action control, motivational conflict, relapse/lapse, skill acquisition, automaticity и feedback learning.

Главная граница:

```text
сознательное принятие задачи
может влиять на поведение

≠
один акт выбора мгновенно создаёт
устойчивую систему решений
```

## Граница параметра

SP-S3-P06 не определяет:

- главную боль — SP-S3-P07;
- следующий навык — SP-S3-P08;
- телесные и жизненные проявления;
- практики;
- критерии перехода;
- ловушку ступени — SP-S3-P13.
