# Визуальные модели Selection Point

**Статус:** действующий фундаментальный вспомогательный слой  
**Дата введения:** 5 июля 2026 года  
**Дата обновления:** 19 августа 2026 года

Утверждены только две визуальные модели:

- SP-VM-01 — «Граф траекторий выбора»;
- SP-VM-02 — «Пространство 1, Пространство 2 и фактическая следующая позиция».

Они не являются самостоятельным доказательством и не добавляют неутверждённый смысл.

---

## SP-VM-01 — Граф траекторий выбора

> **Каждый ход создаёт поле следующего хода.**

```text
текущая позиция
→ поле ходов
→ следующий ход
→ следующая позиция
```

Для SP-S3-P01:

```text
один иной доступный ход
≠ устойчивая собственная линия
```

Для SP-S3-P02:

```text
ожидаемая ветвь
≠ гарантированная ветвь

фактическая следующая позиция
= новые данные для выбора
```

Для SP-S3-P03:

```text
текущая конфигурация человека
→ доступный ход
→ действие
→ последствия
→ следующая позиция
→ повторение
→ изменение реальной способности
→ уточнение модели себя
```

Для SP-S3-P04:

```text
текущая позиция
→ активная внутренняя задача
→ критерий значимости и приоритета
→ доступный ход
→ действие / бездействие
→ независимая следующая позиция
→ обратная связь
→ следующий цикл
```

Для SP-S3-P05:

```text
текущая позиция
→ активная задача A
→ задача A становится различимой
→ [функциональное окно выбора]
→ сохранить / уточнить A
  или принять задачу B
→ изменённый критерий приоритета
→ следующий доступный ход
→ фактическая следующая позиция
```

P05 добавляет не новую ветвь графа как таковую, а возможность изменить критерий, относительно которого доступные ветви получают приоритет.

Для SP-S3-P06:

```text
сознательно выбранная задача
→ может изменить следующий ход
→ фактическая следующая позиция
→ следующий цикл

но

один выбранный ход
≠ устойчивая новая траектория
```

P06 запрещает читать граф так, будто выбор нового критерия автоматически создаёт устойчивую линию. Устойчивость обнаруживается и формируется через последовательность фактических ходов, следующих позиций и корректировок.

Ключевые границы:

```text
один новый поступок
≠ доказательство новой идентичности

заявленная задача
≠ фактически действующий организатор

изменить действие
≠ изменить задачу

сознательно выбрать задачу
≠ сформировать устойчивый управляющий приоритет

несколько организованных ходов
≠ гарантированная внешняя траектория
```

## SP-VM-02 — Пространство 1, Пространство 2 и фактическая следующая позиция

```text
Пространство 1
= то, что фактически существует сейчас

Пространство 2
= представленное возможное или желаемое будущее

ход
= доступное участие человека

фактическая следующая позиция
= то, что реально возникло после действия,
  бездействия, ответа среды и последствий
```

Для SP-S3-P02 действует формула:

> **Пространство 1 не определяет всё будущее, а Пространство 2 не обладает правом требовать от будущего соответствия себе.**

Для SP-S3-P03:

```text
текущий образ себя
= часть модели Пространства 1
≠ окончательная сущность

представление «каким я стану»
= возможное Пространство 2
≠ гарантированная будущая идентичность
```

Для SP-S3-P04:

```text
созидательная внутренняя задача
может использовать Пространство 2
как представленное направление или критерий

но

внутренняя задача
≠ Пространство 2

Пространство 2
≠ гарантированный результат

фактическая следующая позиция
= независимый ответ реальности,
  используемый для корректировки
```

Для SP-S3-P05:

```text
сознательно принятая задача
→ меняет критерий организации участия

но

выбор задачи
≠ выбор Пространства 2 как гарантии

смена задачи
≠ контроль фактической следующей позиции
```

Для SP-S3-P06:

```text
выбранная задача
≠ сформированная способность

согласованный следующий ход
≠ гарантированная устойчивая линия

Пространство 2
≠ доказательство того,
что внутренняя система уже перестроена
```

Фактическая следующая позиция остаётся данными и о внешнем ответе, и о том, насколько выбранная задача реально участвовала в организации поведения.

## Связь с SP-SRC-001

```text
активная задача / внутренняя модель
→ внимание и поле ходов
→ действие или бездействие
→ ответ среды
→ фактическая следующая позиция
→ корректировка моделей и условий следующего цикла
```

SP-S3-P05 добавляет возможность повторного участия в этом контуре: после различения действующей задачи следующий цикл не обязан автоматически сохранять прежний критерий приоритета.

SP-S3-P06 добавляет границу между сознательным выбором и устойчивым формированием: выбранная задача становится одним причинным фактором, но её управляющее присутствие проверяется через повторяющиеся реальные циклы.

SP-SRC-001 остаётся приоритетным первичным источником и не изменяет визуальные модели автоматически.

## Границы

Визуальные модели не доказывают:

- полный контроль результата;
- равную доступность всех вариантов;
- возможность стать кем угодно независимо от истории, биологии и среды;
- что новый образ будущего создаёт новую личность;
- что один поступок доказывает изменение идентичности;
- что сознательно сформулированная задача автоматически управляет поведением;
- что любая задача может быть мгновенно переключена волевым решением;
- что один акт выбора задачи мгновенно создаёт устойчивую систему поведения;
- что несогласованный ход отменяет реальность предыдущего выбора;
- что постоянный сознательный контроль необходим для устойчивой линии;
- что задача или направление внимания создают внешние события;
- что фактическая следующая позиция полностью создана человеком;
- что Пространство 2 гарантирует результат.

Новая визуальная модель для SP-S3-P06 не утверждалась; SVG-файлы не изменялись.
