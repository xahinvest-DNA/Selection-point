# Визуальные модели Selection Point

**Статус:** действующий фундаментальный вспомогательный слой  
**Дата введения:** 5 июля 2026 года  
**Дата обновления:** 28 августа 2026 года

Утверждены только две визуальные модели:

- SP-VM-01 — «Граф траекторий выбора»;
- SP-VM-02 — «Пространство 1, Пространство 2 и фактическая следующая позиция».

Они не являются самостоятельным доказательством и не добавляют неутверждённый смысл.

---

## SP-VM-01 — Граф траекторий выбора

> **Каждый ход создаёт поле следующего хода.**

```text
текущая позиция
→ поле ходов
→ следующий ход
→ следующая позиция
```

Для SP-S3-P01–P08 модель различает отдельный ход, выбранную задачу, устойчивость и обратную связь.

Для P09:

```text
состояние X
→ раньше почти обязательный A

состояние X
→ позже реально доступны A и B
```

Для P10:

```text
позиция
→ ход
→ ответ среды
→ следующая позиция
→ следующий цикл
```

Для P11 наблюдение может увеличить различимость текущей позиции и поля ходов, не изменяя самого внешнего факта.

Для P12 повторяемая доступность операции в разных обычных позициях становится материалом будущей оценки переноса способности.

Для P13 граф приобретает дополнительную функцию: фактическая следующая позиция должна оставаться способной изменить модель следующего цикла.

```text
текущая модель
→ ход
→ независимый ответ среды
→ фактическая следующая позиция
→ данные
→ уточнение / сохранение / пересмотр модели
→ следующий цикл
```

Ловушка P13:

```text
текущая модель
→ ход
→ ответ среды
→ любой результат получает
  совместимое с моделью объяснение
→ модель подтверждает сама себя
```

Следовательно:

```text
обратная связь существует
≠ обратная связь выполняет
корректирующую функцию
```

### Связь с SP-S4-P01

На Ступени 4 одна и та же внешняя позиция может давать разное практически доступное поле ходов в зависимости от нагрузки.

```text
позиция X
+ обычная нагрузка
→ A / B / C / пауза

позиция X
+ высокая нагрузка
→ практически доступен A
или A / B
```

Граф не утверждает, что остальные варианты объективно исчезли; он показывает изменение их практической доступности человеку.

Он также позволяет различать:

```text
сохранить наблюдение
≠ сохранить влияние на действие
≠ вернуть выбор после временной потери
```

## SP-VM-02 — Пространство 1, Пространство 2 и фактическая следующая позиция

```text
Пространство 1
= то, что фактически существует сейчас

Пространство 2
= представленное возможное или желаемое будущее

ход
= доступное участие человека

фактическая следующая позиция
= то, что реально возникло после действия,
  бездействия, ответа среды и последствий
```

Для P09 телесное состояние является частью текущего Пространства 1.

Для P10 выбранная задача может организовывать ход, но не гарантирует фактическую следующую позицию.

Для P11 текущая позиция различается как минимум через внешний факт, внутреннюю реакцию, добавленное значение и неизвестное.

Для P12 одновременно удерживаются внешний причинный вклад и доступная часть собственного участия.

Для P13 особенно важно:

```text
моя модель Пространства 1
≠ само Пространство 1 целиком
```

и:

```text
фактическая следующая позиция
может содержать данные,
которые требуют изменить
мою текущую модель
```

Пространство 2 также не получает иммунитет от реальности только потому, что человек сознательно выбрал направление.

### Связь с SP-S4-P01

Нагрузка является частью текущего Пространства 1 и может менять поле практически доступного участия.

```text
Пространство 1
= внешний факт
+ состояние тела
+ уровень возбуждения / усталости
+ временное давление
+ социальные и иные ограничения
+ реально доступные ходы
```

Это не означает, что состояние полностью определяет продолжение. P01 фиксирует только то, что доступность ранее сформированной способности может существенно меняться под нагрузкой.

## Связь с исходными материалами

SP-SRC-001 — причинный контур мысли, внимания, действия, среды и следующей позиции.

SP-SRC-002:

```text
осознанно выбрано ≠ полезно
```

SP-SRC-003:

```text
сознательно выбранная задача
≠ уже перестроенная
телесно-поведенческая организация
```

SP-SRC-004:

```text
направление без движения
≠ создаваемая траектория
```

SP-SRC-005:

```text
способность в упражнении
≠ способность в жизни
```

SP-SRC-006:

```text
уверенность ≠ догма
данные ≠ интерпретация данных
пересматриваемость ≠ хроническое сомнение
```

SP-SRC-007:

```text
уметь в спокойной ситуации
≠ иметь доступ к способности под нагрузкой

автоматизм
≠ автоматизация освоенного навыка
```

Главная опора P13:

> **Модель остаётся рабочей только пока реальность сохраняет возможность её изменить.**

Главная формула SP-S4-P01:

> **Под нагрузкой проявляется не только то, что я знаю, — проявляется то, что во мне действительно натренировано.**

## Границы

Визуальные модели не доказывают:

- полный контроль результата;
- равную доступность всех вариантов;
- что задача или внимание создают внешние события;
- что фактическая следующая позиция полностью создана человеком;
- что внешняя успешность доказывает более высокую ступень;
- что наблюдение автоматически даёт точную модель;
- что больше деталей автоматически означает большую точность;
- что перенос способности между областями уже доказан;
- что любой отрицательный результат опровергает модель;
- что любой положительный результат подтверждает модель;
- что уверенность означает закрытость;
- что любую модель необходимо постоянно пересматривать;
- что высокая нагрузка всегда уменьшает выбор одинаковым способом;
- что под нагрузкой всегда срабатывает «самый тренированный» навык;
- что натренированный автоматизированный ответ обязательно адекватен реальности.

Новая визуальная модель для SP-S4-P01 не утверждалась; SVG-файлы не изменялись.
