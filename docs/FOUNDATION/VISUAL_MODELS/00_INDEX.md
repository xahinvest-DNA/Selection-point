# Визуальные модели Selection Point

**Статус:** действующий фундаментальный вспомогательный слой  
**Дата введения:** 5 июля 2026 года  
**Дата обновления:** 20 августа 2026 года

Утверждены только две визуальные модели:

- SP-VM-01 — «Граф траекторий выбора»;
- SP-VM-02 — «Пространство 1, Пространство 2 и фактическая следующая позиция».

Они не являются самостоятельным доказательством и не добавляют неутверждённый смысл.

---

## SP-VM-01 — Граф траекторий выбора

> **Каждый ход создаёт поле следующего хода.**

```text
текущая позиция
→ поле ходов
→ следующий ход
→ следующая позиция
```

Для SP-S3-P01–SP-S3-P07 сохраняются ранее утверждённые связи: один ход не равен устойчивой линии; выбранная задача организует критерий приоритета; акт выбора не равен сформированной устойчивости; откат не обнуляет реальную траекторию.

Для SP-S3-P08:

```text
выбранная задача B
→ реальный ход
→ фактическая следующая позиция
→ обратная связь
→ следующий выбор
```

Последовательность фактических позиций используется для различения трёх объектов корректировки:

```text
1. управляющее присутствие задачи
2. способ решения задачи
3. сама задача
```

Если основания B сохраняются, но B потеряла управляющий приоритет, следующий ход может восстанавливать её присутствие. Если способ M не работает, может меняться M без автоматической отмены B. Если накопленная траектория подрывает основания B, сама B может быть уточнена или заменена.

Ключевые границы:

```text
один результат
≠ окончательный вердикт о задаче

положительный ход
≠ доказательство полезности задачи

негативный ход
≠ автоматическое опровержение задачи

изменить способ
≠ обязательно изменить задачу

изменить задачу
≠ потерять авторство
```

## SP-VM-02 — Пространство 1, Пространство 2 и фактическая следующая позиция

```text
Пространство 1
= то, что фактически существует сейчас

Пространство 2
= представленное возможное или желаемое будущее

ход
= доступное участие человека

фактическая следующая позиция
= то, что реально возникло после действия,
  бездействия, ответа среды и последствий
```

Для SP-S3-P01–SP-S3-P07 сохраняются утверждённые различения между фактом, представленным будущим, выбранной задачей, сформированной способностью и фактической следующей позицией.

Для SP-S3-P08:

```text
Пространство 2
≠ доказательство полезности задачи

достижение Пространства 2
≠ автоматическое подтверждение,
что выбранная линия полезна

неполучение Пространства 2
≠ автоматическое опровержение задачи

фактическая следующая позиция
= данные для сохранения,
  восстановления, уточнения
  или пересмотра линии
```

Обратная связь не является приказом среды и не отменяет авторство следующего выбора.

## Связь с исходными материалами

SP-SRC-001 сохраняет причинный контур:

```text
активная задача / внутренняя модель
→ внимание и поле ходов
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ корректировка следующего цикла
```

SP-SRC-002 добавляет для P08 границу:

```text
осознанно выбрано ≠ полезно
созидание ≠ улучшение
авторство ≠ мудрость
```

Поэтому новая линия не считается благом только потому, что человек способен последовательно её реализовывать.

## Границы

Визуальные модели не доказывают:

- полный контроль результата;
- равную доступность всех вариантов;
- возможность стать кем угодно независимо от истории, биологии и среды;
- что сознательно сформулированная задача автоматически управляет поведением;
- что один акт выбора мгновенно создаёт устойчивую систему;
- что один откат отменяет реальность предыдущего выбора;
- что повторный выбор означает начало с нуля;
- что постоянный сознательный контроль необходим для устойчивой линии;
- что выбранная задача автоматически полезна;
- что положительный результат подтверждает правильность задачи;
- что негативный результат опровергает задачу;
- что задача или внимание создают внешние события;
- что фактическая следующая позиция полностью создана человеком;
- что Пространство 2 гарантирует результат или процветание.

Новая визуальная модель для SP-S3-P08 не утверждалась; SVG-файлы не изменялись.
