## 1. Последний утверждённый параметр

**SP-S4-P04 — «Что управляет решениями» — утверждён.**

Ключевые положения:

> **Под нагрузкой важна не неизменность задачи, а сохранение её осознанного места в иерархии решений.**

> **Выбранная задача определяет не конкретный ход, а принцип организации ходов.**

```text
организующий приоритет
≠ оперативный приоритет

реальность изменила основание решения
≠ состояние вытеснило выбранную задачу
```

## 2. Что произошло с SP-S4-P05

P05 был открыт и перед полным архитектурным разбором прошёл обязательную трёхвопросную рефлексию.

Сравнительная реконструкция через Вильямса, Миллмэна и Фрица дала рабочие гипотезы:

- на S4 новая способность выбирать, вероятно, не появляется; проверяется доступность уже сформированной способности под нагрузкой;
- сильное состояние не равно автоматически потерянному выбору;
- спокойствие не равно автоматически сохранённому выбору;
- буквальная модель единственной особой «точки выбора» может быть избыточной;
- рабочая альтернатива — вновь возникающая доступность участия в следующем ходе из фактической текущей позиции;
- `zero-delta` остаётся допустимым исходом.

После принятия этой рефлексии была установлена временная явная пауза. Этот факт остаётся в истории и не переписывается.
