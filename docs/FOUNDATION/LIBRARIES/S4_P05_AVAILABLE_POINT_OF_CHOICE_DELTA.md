# SP-S4-P05 — Parameter Delta: Available Point of Choice Under Load

**Статус:** утверждённая локальная дельта  
**Дата:** 29 августа 2026 года  
**Параметр:** SP-S4-P05  
**Полный источник:** `../FIVE_STAGES_THEORY/44_STAGE_4_AVAILABLE_POINT_OF_CHOICE.md`  
**Канон:** `../CANONICAL/36_STAGE_4_P05_CANONICAL.md`  
**Reality Check:** RC-009

## 1. Новый claim

> **Под нагрузкой доступность выбора сохраняется не потому, что человек способен придумать как можно больше вариантов, а потому, что выбранное направление не схлопывается для него в один субъективно обязательный ход. Если фактическая текущая позиция допускает иные продолжения, хотя бы часть из них остаётся практически различимой и доступной.**

Короткая формула:

> **Выбранное направление ≠ единственный воспринимаемый ход.**

## 2. Самостоятельная дельта

```text
S3-P05:
я могу выбирать,
для чего совершается следующий ход

S4-P05:
под нагрузкой я сохраняю выбранное направление,
не превращая один возникший ход
в единственно возможное продолжение,
если фактическая позиция допускает другие
```

## 3. Новое различение

```text
объективно узкое поле
≠
субъективно схлопнувшееся поле
```

И:

```text
я способен представить другой ход
≠
другой ход практически доступен сейчас
```

## 4. Граница с P04

```text
P04:
какое направление сохраняет организующий приоритет?

P05:
какие ходы внутри этого направления
остаются practically available?
```

Ключевой наблюдаемый эпизод Architect pass:

```text
значимое направление сохранилось
+
изменилась ширина доступного поля продолжений
```

Это является основным основанием самостоятельной дельты P05 относительно P04.

- `pilot-observability-pending`;
- `falsifier-defined`.

## 7. Falsifier

Дельта требует пересмотра, если:

1. поле practically available ходов неотличимо от P01/P02/P04;
2. схлопывание направления в один ход определяется только задним числом;
3. объективно один возможный ход ошибочно трактуется как потеря выбора;
4. параметр требует максимизации количества вариантов;
5. конкретный телесный сигнал становится универсальным критерием;
6. различение не улучшает описание реальных эпизодов и простого ядра.

## 8. Terms / risks / visuals

Новая обязательная глобальная сущность не вводится.

«Поле practically available ходов» используется как локальное описательное различение P05; при консолидации предпочтителен русский язык: **поле практически доступных продолжений / ходов**.

Применимые риски:

- иллюзия равной доступности направлений;
- объявление реального ограничения иллюзией;
- тело как безошибочная истина;
- ретроспективная реконструкция;
- more-options fallacy;
- premature-skilling;
- homunculus risk.

Новая SVG-модель не требуется.

## 9. Решение по периферическому зрению

Наблюдение владельца о расширении поля при намеренном включении периферического зрения сохраняется как pilot signal для будущих P09/P11.

Оно **не входит** в каноническое определение P05 и **не считается** универсальной практикой или доказанным причинным механизмом.

## 10. Консолидация

P05 является плановой точкой консолидации библиотек. После создания этой delta утверждённые изменения SP-S4-P03–P05 должны быть отражены в общих claims/evidence/cross-reference/risk registries без изменения утверждённого смысла предыдущих параметров.
