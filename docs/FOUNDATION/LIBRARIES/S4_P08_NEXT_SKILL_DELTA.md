## Новый claim

> **Следующий навык четвёртой ступени — способность восстанавливать функциональное участие из фактической степени текущей доступности после того, как под нагрузкой уменьшился доступ к уже сформированной способности выбора.**

Короткая формула:

> **Восстанавливать участие из фактической доступности.**

## Новое practically useful distinction

```text
P01:
фактическая доступность способности может снижаться

P05:
practically available поле продолжений может сужаться

P06:
сформированность не гарантирует будущую доступность

S3-P08:
вести выбранную задачу через обратную связь

S4-P08:
после снижения доступа к самой способности
снова функционально войти в цикл
из реально оставшейся доступности
```

## Ключевые границы

```text
восстановить участие
≠
сначала полностью восстановить прежнее состояние

полное прежнее состояние не всегда нужно
≠
состояние никогда не нужно восстанавливать

больше вариантов
≠
больше зрелости

минимально достаточное участие
≠
полный контроль

пауза / выход / помощь
≠
автоматически потеря авторства
```

## Новые термины

Новый обязательный глобальный термин не вводится.

Рабочее выражение **«фактическая степень текущей доступности»** используется как уточнение уже существующего понятия доступности способности и не требует отдельной онтологической сущности.

## Новые риски / границы

1. **Forced-control risk:** P08 может быть ошибочно превращён в требование «немедленно взять себя в руки».
2. **More-options risk:** навык может быть ошибочно сведен к максимизации количества вариантов.
3. **Anti-regulation risk:** формулу можно неверно прочитать как запрет восстанавливать состояние.
4. **Retrospective participation risk:** любое действие может задним числом называться «участием» без наблюдаемой связи с фактами и направлением.
5. **Conscious-analysis risk:** зрелость может быть ошибочно приравнена к длинному самоанализу, игнорируя автоматизированный зрелый ответ.
6. **Novelty overclaim risk:** близость к psychological flexibility / self-regulation запрещает заявлять P08 как новый универсальный психологический механизм.

## Evidence delta

RC-012 фиксирует:

- `externally-compatible` — context-dependent executive availability, psychological flexibility, dynamic self-regulation, strategic automation;
- `externally-limited` — стресс не всегда ухудшает контроль; восстановление состояния иногда необходимо; внешние модели сильно соседствуют с P08;
- `pilot-observability-pending`;
- `falsifier-defined`;
- `internal-approved` после решения владельца 30 августа 2026 года.

Внешняя совместимость отдельных компонентов не доказывает пятиступенчатую архитектуру Selection Point.

## Visual delta

Новая визуальная модель не требуется. Существующая логика «фактическая позиция → доступный ход → следующая позиция → обратная связь» достаточна и не должна усложняться ради P08.

## Falsifier

P08 требует пересмотра или `zero-delta`, если:

- его невозможно отличить от P01 + P05 + S3-P08;
- любое действие можно объявить участием независимо от фактов;
- критерий становится ретроспективным успехом результата;
- параметр сводится к числу вариантов;
- самостоятельное practical consequence для будущей архитектуры исчезает.
