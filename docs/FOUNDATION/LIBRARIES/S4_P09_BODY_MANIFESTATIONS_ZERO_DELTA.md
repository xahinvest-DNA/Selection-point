## Результат проверки дельты

Самостоятельная новая архитектурная дельта для P09 не подтверждена.

```text
S4-specific body-manifestations delta
=
0
```

Это не означает, что тело не имеет значения.

Утверждено другое:

```text
тело
=
часть текущей позиции
+
может участвовать в дальнейшей динамике состояния
```

Но:

```text
body-state bidirectionality
≠
unique S4 mechanism
```

## Почему zero-delta

Рабочее содержание P09 после повторного Reality Check распределяется между уже существующими слоями:

```text
HCM-02:
состояние меняет восприятие и действия;
действие может менять состояние

S1-P09:
тело — условие, носитель реакции и результат

S3-P09:
телесное состояние влияет на поле ходов,
но не полностью определяет выбор

S4-P01:
доступность сформированной способности
может снижаться под нагрузкой

S4-P08:
участие может восстанавливаться
до полной нормализации состояния
```

После вычитания этих слоёв отдельной S4-specific телесной структуры не обнаружено.

## Утверждённые границы

```text
телесный сигнал = данные
≠ только данные
```

```text
изменение тела может влиять на состояние
≠ гарантирует изменение состояния
```

```text
улучшение состояния
≠ восстановление выбора
```

```text
напряжение ≠ потеря выбора
спокойствие ≠ наличие выбора
```

```text
телесный показатель
≠ универсальный биомаркер выбора
```

## P09 / P11 boundary

Намеренное использование телесного компонента текущей позиции как возможного входа для изменения состояния / доступности является кандидатом функционального класса SP-S4-P11.

```text
намеренное телесное воздействие
→ candidate P11 functional class
≠ P09 manifestation
```

Конкретные техники не утверждены.
