## 1. Новый claim

> **Главная иллюзия четвёртой ступени возникает, когда реально сформированная способность сохранять выбор начинает переживаться как гарантия собственной будущей доступности. Когда факты нарушают эту гарантию, они возвращают человека к текущей позиции; это само по себе не доказывает ни утрату способности, ни ошибочность выбранного направления.**

Короткая формула:

> **Сформированная способность ≠ гарантированная доступность.**

## 2. Самостоятельная функция P06

P06 не вводит отдельный новый причинный механизм. Как параметр «Главная иллюзия» он собирает P01–P05 в одно специфическое ложное равенство ступени.

```text
реальный рост способности
→
высокая повторяемость успешного доступа
→
ошибочная безусловная гарантия
```

## 3. Наблюдаемое различение с P01

```text
P01:
фактическая доступность навыка сейчас

P06:
калибровка ожидания о его будущей доступности
```

P01 without P06:

```text
навык временно недоступен,
но это принято как факт позиции
```

P06 without current P01 failure:

```text
навык доступен,
но его будущая доступность уже считается гарантированной
```

## 4. Новые канонические границы

```text
мастерство повышает вероятность доступности
≠
мастерство гарантирует доступность
```

```text
потеря гарантии
≠
потеря способности
```

```text
разочарование
→ факты
≠ автоматический пересмотр направления
```

При этом:

```text
релевантные новые факты
об основании / пригодности / достижимости направления
→
могут потребовать пересмотра
```

## 7. Falsifier

Дельта требует пересмотра, если:

1. ожидание гарантии не удаётся наблюдать независимо от срыва;
2. P06 полностью сводится к P01/P03/P05;
3. высокая уверенность начинает трактоваться как патология;
4. любой сбой автоматически объявляется доказательством P06;
5. `dis-illusion` становится нефальсифицируемой идеей;
6. устойчивость используется для игнорирования релевантных фактов;
7. различение возможно только задним числом.

## 8. Terms / risks / visuals

Новая обязательная глобальная сущность не вводится.

Допустимые локальные выражения:

- «гарантия доступности»;
- «калибровка ожидания доступности»;
- `dis-illusion` — только как литературно-функциональный мост к возвращению модели к фактам, не как отдельный универсальный механизм.

Ключевые риски:

- false-modesty / разрушение полезной уверенности;
- hindsight reconstruction;
- anti-persistence;
- защита направления от фактов;
- метафоризация `dis-illusion` без наблюдаемого содержания;
- duplication с P01/P03/P05.

Новая визуальная модель не требуется.

## 9. Консолидация

P06 не является плановой точкой большой консолидации. Локальная delta достаточна до P10, если отдельное решение владельца не потребует более раннего обновления крупных реестров.
