# Case Study — Комашня: замыкание модели через «эго» и присвоенную причинность

**Статус:** исследовательский кейс / материал для дальнейшей проверки  
**Дата фиксации:** 1 сентября 2026 года  
**Не является каноническим утверждением Selection Point.**

## Источник кейса

Публичный ролик Дмитрия Комашни, опубликованный 1 сентября 2026 года, и комментарий подписчицы под роликом.

По прямому просмотру ролика автором проекта SP, Комашня утверждает, что произошедшую внешнюю ситуацию он «создал своими мыслями», при этом негативный результат связывает с собственным «эго».

Контекст ролика связан с трагическим внешним событием в Черногории и последовавшим общественным трауром. Для SP существенен не сам внешний эпизод, а способ построения причинного объяснения.

В комментарии подписчица замечает возможное противоречие: человек, обучающий «целостности» и выходу из «разделения», сам использует формулировку, которую она воспринимает как разделяющую. После этого она разворачивает сомнение обратно на себя: если она увидела разделение, значит, «сама ещё находится в разделении».

## Почему кейс важен для Selection Point

Кейс одновременно затрагивает:

- авторство;
- причинность;
- границу между внутренним состоянием и внешним событием;
- работу с несоответствием;
- роль «эго» как универсального объяснительного слоя;
- способность модели принимать корректирующую обратную связь;
- риск самозамыкающихся мировоззренческих систем;
- перенос обнаруженного противоречия с модели на наблюдателя.

## Основной паттерн

```text
факт реальности
→ факт не укладывается в мировоззренческую модель
→ возникает потенциальный Selection Point
→ вместо проверки или пересмотра модели
→ событие присваивается внутренней причинности: «это создали мои мысли / моё эго»
→ исходная модель снова способна объяснить результат
→ противоречие перестаёт иметь силу обратной связи
```

Рабочая интерпретация для SP: это возможный механизм **замыкания модели**.

Модель сохраняет объяснительную власть независимо от того, какой результат появился в реальности.

## Вторичный паттерн: перенос противоречия на наблюдателя

Комментарий подписчицы показывает отдельный механизм:

```text
наблюдатель замечает противоречие в поведении учителя
→ появляется сомнение
→ сомнение интерпретируется языком самой модели
→ «если я вижу разделение, значит, разделение находится во мне»
→ обнаруженное несоответствие перестаёт проверять учителя или модель
→ сомнение становится свидетельством недостаточной развитости наблюдателя
→ модель сохраняется
```

Это особенно важно для SP, потому что здесь сама способность заметить несоответствие может быть переопределена как дефект наблюдателя.

## Граница авторства и причинности

Рабочее различение:

### Наблюдаемая причинная цепочка

```text
мысль / интерпретация
→ внимание и состояние
→ выбор
→ действие или бездействие
→ последствия
→ изменение следующей позиции
```

В такой цепочке человек может обоснованно исследовать собственное участие и авторство.

### Приписанная причинность

```text
моя мысль
→ независимое внешнее событие, совершённое другими людьми
```

Если промежуточный причинный механизм не установлен, утверждение о таком авторстве остаётся гипотезой, а не установленным фактом.

Для SP важно не отрицать возможное влияние мышления на реальность, а различать:

- наблюдаемое участие;
- интерпретацию;
- гипотезу;
- установленную причинность.

## Роль «эго» как защитного объяснения

Рабочая гипотеза:

```text
желаемый результат → «я создал это»
нежелательный результат → «это создало моё эго»
```

Если обе ветви автоматически подтверждают одну и ту же мировоззренческую посылку, система становится трудноопровержимой.

Критический вопрос SP:

> Какой наблюдаемый факт должен появиться, чтобы модель признала: её объяснение было ошибочным или недостаточным?

Если ответ фактически равен «никакой», модель теряет канал коррекции реальностью.

## Предварительные принципы для дальнейшей разработки SP

### 1. Модель должна быть способна проиграть реальности

Если любой возможный результат заранее может быть превращён в подтверждение модели, несоответствие перестаёт выполнять корректирующую функцию.

### 2. Ответственность требует различимой причинной связи

Рабочая формулировка:

> **Ответственность заканчивается там, где заканчивается наблюдаемая причинная связь; дальше начинается приписывание причинности.**

Формулировка требует дальнейшей проверки и уточнения: человек может участвовать в сложных системах косвенно, поэтому «наблюдаемая» не должна сводиться только к непосредственному физическому действию.

### 3. Признак закрытой модели

Рабочая формулировка:

> **Зрелая модель способна объяснить собственную ошибку. Закрытая модель объясняет, почему человек, заметивший ошибку, ещё недостаточно развит, чтобы понять, что ошибки нет.**

Это не канонический тезис, а диагностическая гипотеза для дальнейшей разработки.

### 4. Несоответствие не должно автоматически превращаться в дефект наблюдателя

Если обнаруженное противоречие каждый раз объясняется «эго», «разделением», «сопротивлением», «неосознанностью» или недостаточной развитостью наблюдателя, модель получает защиту от внешней проверки.

SP должен сохранять возможность другого хода:

```text
заметил несоответствие
→ остановился
→ отделил факт от интерпретации
→ задал вопрос
→ проверил причинность
→ допустил ошибку собственной модели
→ при необходимости обновил модель
```

## Связь с Selection Point

Кейс особенно релевантен следующим темам:

- доступная точка выбора под напряжением;
- способность остановиться перед автоматическим объяснением;
- различение факта и интерпретации;
- обнаружение несоответствия;
- проверка причинной модели;
- защита образа себя или мировоззрения;
- уменьшение Selection Capacity через закрытие обратной связи;
- возможность пересмотра модели без потери авторства.

## Ограничения кейса

- Полная стенограмма ролика на момент фиксации в репозитории отсутствует.
- Формулировка о «создании ситуации мыслями» зафиксирована со слов автора проекта после прямого просмотра ролика и требует сохранения полной записи/стенограммы при появлении такой возможности.
- Нельзя по одному ролику делать вывод о всей системе взглядов человека или о его психологических мотивах.
- Кейс используется как материал для анализа структуры объяснения, а не как диагноз личности.

## Короткая рабочая формула

```text
несоответствие
→ возможное сомнение
→ либо проверка модели
→ либо защитное объяснение, которое делает модель неопровержимой
```

Для Selection Point критичен первый маршрут: **обратная связь должна сохранять право изменить модель**.
