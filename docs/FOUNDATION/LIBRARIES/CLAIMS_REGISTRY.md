### Утверждённые формулы SP-S3-P04

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

> **Заявленная цель говорит, чего я хочу. Внутренняя задача проявляется в том, что реально начинает организовывать мои решения.**

> **Свобода становится созидательной, когда человек способен не только отказаться от автоматической задачи, но и принять задачу, которая начинает организовывать его следующие ходы.**

### Утверждённые формулы SP-S3-P05

> **Я могу выбрать, для чего будет сделан следующий ход.**

> **Мне не обязательно продолжать решать ту задачу, которая сейчас стала главной. Я могу выбрать, какую задачу будет решать мой следующий ход.**

Ключевое различение:

```text
изменить действие
≠
изменить задачу

сформулировать новую задачу
≠
передать ей критерий приоритета следующего хода
```

### Утверждённые формулы SP-S3-P06

> **Я выбрал задачу — значит теперь я действую из неё.**

> **Выбор задачи начинает новую линию, но ещё не создаёт устойчивую систему.**

> **Выбрать задачу — не значит закончить выбирать.**

> **Выбор запускает формирование, но не является самим сформированным результатом.**

Ключевое различение:

```text
задача сознательно выбрана
≠
задача получила устойчивый управляющий приоритет
```

```text
один согласованный ход
≠ устойчивая система

один несогласованный ход
≠ отсутствие сделанного выбора
```

## Связанный приоритетный первичный источник

SP-SRC-001 — «Как мысль становится материальной» — остаётся приоритетным первичным источником, но не становится каноном автоматически.

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Для SP-S3-P04 источник уточнён замкнутой петлёй: активная задача и модели организуют внимание и действия, а фактическая следующая позиция возвращает данные, способные подтвердить, ослабить или изменить модели и последующее поле выбора.

SP-S3-P05 добавляет функциональное окно, в котором различённая задача перестаёт автоматически обладать правом организовывать продолжение, а критерий следующего доступного хода может быть сознательно сохранён, уточнён или изменён.

SP-S3-P06 добавляет границу между актом выбора задачи и формированием устойчивой системы: один выбор может изменить следующий цикл, но не считается доказательством устойчивого управляющего приоритета.

## Правило использования реестра

- Стабильный ID используется вместо повторного полного объяснения утверждённой основы.
- Короткая запись не заменяет полный теоретический файл.
- При расхождении приоритет имеет последнее явное решение Андрея, затем фундаментальные документы и полный утверждённый источник.
- Новые положения не добавляются без явного утверждения.
