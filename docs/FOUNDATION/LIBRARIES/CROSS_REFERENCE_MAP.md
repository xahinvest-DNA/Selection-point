# Карта перекрёстных связей Selection Point

**Статус:** действующая навигационная библиотека  
**Дата обновления:** 19 августа 2026 года

Карта показывает, какие утверждения являются основанием для следующих элементов и где искать полный смысл. Она является производным навигационным слоем и не заменяет полную теорию и канон.

---

## Сквозная последовательность

```text
SP-HCM-01–SP-HCM-09
→ SP-S1-P01–SP-S1-P13
→ SP-S2-P01–SP-S2-P13
→ SP-S3-P01
→ SP-S3-P02
→ SP-S3-P03
→ SP-S3-P04
→ SP-S3-P05
```

Ступень 1 содержательно завершена. Ступень 2 содержательно завершена. Ступень 3 активна.

---

## Переход от Ступени 2 к Ступени 3

```text
сценарий перестаёт быть единственным организатором
→ антисценарий не должен закрыть открытый вопрос
→ SP-S3-P01:
  внутренняя рекомендация ≠ решение
→ SP-S3-P02:
  внешний факт ≠ автоматически заданный смысл и единственное продолжение
→ SP-S3-P03:
  текущий образ себя ≠ окончательная сущность и обязательное будущее
→ SP-S3-P04:
  человек начинает участвовать в выборе задачи,
  относительно которой организуются следующие ходы
→ SP-S3-P05:
  различённая задача перестаёт автоматически обладать
  правом организовывать продолжение;
  критерий следующего хода может быть сохранён,
  уточнён или сознательно изменён
```

Ключевые различения перехода:

```text
освобождение от обязательности сценария
≠ сформированная собственная задача

способность не подчиниться сценарной задаче
≠ способность сознательно принять другую задачу

сформулировать новую задачу
≠ передать ей критерий приоритета следующего хода
```

## SP-SRC-001 и Ступень 3

SP-SRC-001 — «Как мысль становится материальной» — остаётся приоритетным первичным источником:

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Связи:

- мысль / модель → SP-HCM-01, SP-S3-P01–P05;
- внимание → SP-HCM-01, SP-S3-P04–P05;
- состояние → SP-HCM-02, SP-S3-P01, SP-S3-P04–P05;
- образ себя → SP-HCM-04, SP-S3-P03–P05;
- поле выбора → SP-HCM-04, SP-HCM-07, SP-S3-P04–P05;
- действие / бездействие → SP-HCM-05, SP-HCM-09, SP-S3-P02–P05;
- ответ среды → SP-HCM-06, SP-S3-P02, SP-S3-P04–P05;
- следующая позиция → SP-HCM-09, SP-S3-P01–P05, SP-VM-01, SP-VM-02;
- организация действий во времени → SP-HCM-08, SP-S3-P04–P05.

SP-S3-P04 уточняет источник замкнутой петлёй:

```text
активная задача / модели
→ внимание
→ интерпретация
→ поле ходов
→ действие
→ независимый ответ среды
→ следующая позиция
→ обновление моделей и условий следующего цикла
```

SP-S3-P05 добавляет точку повторного участия:

```text
активная задача
→ задача становится различимой
→ функциональное окно выбора
→ сохранить / уточнить задачу
  или сознательно принять другую
→ изменённый критерий следующего хода
```

Источник не становится каноном автоматически.

## SP-S3-P03 — способ восприятия себя

**Полный источник:** `../FIVE_STAGES_THEORY/29_STAGE_3_SELF_PERCEPTION.md`  
**Канонический источник:** `../CANONICAL/21_STAGE_3_P03_CANONICAL.md`

> **То, какой я сейчас, — факт моей текущей позиции, но не окончательный ответ на вопрос, кем я могу стать.**

> **Я не обязан сначала найти «настоящего себя», чтобы начать участвовать в том, кем становлюсь.**

> **Я не выбирал всё, из чего сформировался, но участвую в том, что формируется дальше.**

Связи с HCM:

| Положение | Влияние |
|---|---|
| SP-HCM-01 | образ себя рассматривается как модель, а не непосредственная сущность |
| SP-HCM-04 | образ себя и сценарий участвуют в поле выбора |
| SP-HCM-05 | действие меняет не только ситуацию, но и действующего |
| SP-HCM-06 | последствия дают данные для уточнения модели себя |
| SP-HCM-08 | новая способность формируется через повторяющиеся циклы |
| SP-HCM-09 | участие в следующей позиции не равно авторству всех обстоятельств |

## SP-S3-P04 — что управляет решениями

**Полный источник:** `../FIVE_STAGES_THEORY/30_STAGE_3_DECISION_DRIVERS.md`  
**Канонический источник:** `../CANONICAL/22_STAGE_3_P04_CANONICAL.md`

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

> **Заявленная цель говорит, чего я хочу. Внутренняя задача проявляется в том, что реально начинает организовывать мои решения.**

> **Свобода становится созидательной, когда человек способен не только отказаться от автоматической задачи, но и принять задачу, которая начинает организовывать его следующие ходы.**

### Уровни задачи

```text
оперативная задача
→ организует текущий эпизод

сценарная задача
→ связывает повторяющиеся эпизоды и роль

внутренняя задача
→ фактически действующий организатор приоритета

созидательная внутренняя задача
→ сознательно принятый организатор нескольких циклов
```

### Основной контур P04

```text
текущая позиция + состояние + модели + внешний контекст
→ активная внутренняя задача
→ внимание
→ значимые данные
→ интерпретация
→ поле ходов
→ решение
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ обратная связь
→ изменение моделей / способностей / условий следующего цикла
```

## SP-S3-P05 — доступная точка выбора

**Полный источник:** `../FIVE_STAGES_THEORY/31_STAGE_3_AVAILABLE_POINT_OF_CHOICE.md`  
**Канонический источник:** `../CANONICAL/23_STAGE_3_P05_CANONICAL.md`

Каноническая формула:

> **Я могу выбрать, для чего будет сделан следующий ход.**

Расширенная формула:

> **Мне не обязательно продолжать решать ту задачу, которая сейчас стала главной. Я могу выбрать, какую задачу будет решать мой следующий ход.**

### Дельта P05

```text
SP-S1-P05:
я могу изменить следующий ход

SP-S2-P05:
следующий ход не обязан доказывать,
кто я

SP-S3-P05:
я могу выбирать,
для чего вообще совершается следующий ход
```

### Функциональное окно

P05 не требует одной идеальной секунды до импульса. Задача может стать различимой после активации, в ходе внимания и интерпретации, во время продолжающегося действия, через последствия или перед следующим циклом.

> **Функциональное окно SP-S3-P05 существует там, где действующая задача уже достаточно различима, а продолжение ещё может быть организовано относительно сохранённой, уточнённой или другой сознательно принятой задачи.**

### Точный контур P05

```text
активная задача A
→ A организует внимание и приоритеты
→ A становится различимой как задача
→ [SP-S3-P05]
→ сохранить / уточнить A
  или снять с неё обязательный приоритет
  или сознательно принять B
→ изменённый критерий значимости
→ следующий доступный ход
```

Если различение произошло после действия:

```text
действие из A
→ фактическая следующая позиция
→ A различается через обратную связь
→ [SP-S3-P05]
→ следующий цикл не обязан снова организовываться A
```

### Центральные различения

```text
изменить действие
≠ изменить задачу

отказаться от старой задачи
≠ сознательно принять новую

сформулировать новую задачу
≠ передать ей критерий приоритета следующего хода

выбор задачи
≠ выбор гарантированного результата
```

### Связи с HCM

| Положение | Влияние на SP-S3-P05 |
|---|---|
| SP-HCM-01 | действующая необходимость может быть различена как часть воспринятой модели, а не как вся реальность |
| SP-HCM-05 | смена задачи значима только через реальный следующий ход и создаваемую им позицию |
| SP-HCM-06 | обратная связь может сделать прежнюю задачу различимой и открыть выбор следующего цикла |
| SP-HCM-07 | окно выбора может возникать на нескольких участках процесса |
| SP-HCM-08 | один акт смены задачи не равен устойчивой новой конфигурации |
| SP-HCM-09 | выбор организатора участия не означает контроль внешнего результата |

## Связь SP-S3-P05 с визуальными моделями

### SP-VM-01

```text
текущая позиция
→ активная задача
→ критерий приоритета
→ поле доступных ходов
→ выбранный ход
→ следующая позиция
```

P05 позволяет изменить не только выбранную ветвь, но и критерий, по которому ветви получают приоритет.

### SP-VM-02

```text
сознательно принятая задача
→ организует участие человека

Пространство 2
→ представляет возможное направление / результат

фактическая следующая позиция
→ зависит также от независимого ответа реальности
```

Следовательно:

```text
смена задачи
≠ гарантия Пространства 2
```

Новая визуальная модель не утверждалась.

## Связь SP-S3-P05 с рисками

Особенно значимы:

- SP-RISK-001 — не превращать участие в обвинение;
- SP-RISK-002 — не создавать иллюзию полного контроля;
- SP-RISK-005 — ответственность не равна самообвинению;
- SP-RISK-007 — не подменять профессиональную помощь;
- SP-RISK-014 — не назначать универсальный скрытый мотив;
- SP-RISK-016 — интеллектуальное понимание не равно изменению;
- SP-RISK-019–020 — не предполагать равную доступность и не отрицать реальные ограничения;
- SP-RISK-023 — не требовать более поздней способности слишком рано;
- SP-RISK-025 — AI или ведущий не должен выбирать внутреннюю задачу вместо человека;
- SP-RISK-029 — функциональная гипотеза о задаче должна оставаться проверяемой.

Для P05 эти границы конкретизируются: нельзя считать, что любую задачу можно мгновенно переключить волей; нельзя выводить фактическую задачу только из внешнего поведения; нельзя считать словесную формулировку доказательством реальной смены организатора.

Нового общего риска отдельным ID не вводилось.
