## Переход от Ступени 2 к Ступени 3

```text
сценарий перестаёт быть единственным организатором
→ SP-S3-P01:
  внутренняя рекомендация ≠ решение
→ SP-S3-P02:
  текущий факт ≠ единственное продолжение
→ SP-S3-P03:
  текущий образ себя ≠ окончательная сущность
→ SP-S3-P04:
  человек начинает участвовать в выборе задачи-организатора
→ SP-S3-P05:
  различённая задача может быть сохранена, уточнена или заменена
→ SP-S3-P06:
  выбор задачи ≠ уже сформированная устойчивая система
→ SP-S3-P07:
  неустойчивость реального выбора переживается как невозможность опереться на себя
→ SP-S3-P08:
  опора переносится с неизменности решения
  на способность сохранять, восстанавливать или пересматривать задачу
  через реальные циклы и обратную связь
```

Ключевые различения:

```text
освобождение от сценарной обязательности
≠ сформированная собственная линия

сознательно выбрать задачу
≠ сформировать устойчивый управляющий приоритет

неустойчивость выбранной линии
≠ нереальность сделанного выбора

осознанно выбрано
≠ полезно

сохранение задачи
≠ упрямство

изменение задачи
≠ бегство
```

## SP-SRC-001 — «Как мысль становится материальной»

Приоритетный первичный источник:

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие / бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Для Ступени 3 он поддерживает причинный контур:

```text
активная задача / модели
→ внимание
→ интерпретация
→ поле ходов
→ действие
→ независимый ответ среды
→ следующая позиция
→ обратная связь
→ обновление моделей, способностей и условий следующего цикла
```

SP-S3-P05 добавляет функциональное окно смены задачи; P06 отделяет выбор от устойчивости; P07 фиксирует боль этого расхождения; P08 использует следующие позиции как данные для сохранения, восстановления или пересмотра выбранной линии.

Источник не является каноном автоматически.

## SP-SRC-002 — «Польза выбранной задачи и проверка реальностью»

**Файл:** `../SOURCE_MATERIALS/02_2026-08-19_TASK_BENEFIT_AND_REALITY_VALIDATION.md`  
**Роль:** приоритетная рабочая опора SP-S3-P08.

Ключевая граница:

```text
осознанно выбрано ≠ полезно
созидание ≠ улучшение
авторство ≠ мудрость
```

Следствие для P08:

```text
задача временно потеряла приоритет,
но её основания сохраняются
→ восстановить управляющее присутствие

задача сохраняет основания,
но способ не работает
→ изменить способ

накопленные данные подрывают основания задачи
→ уточнить или изменить саму задачу
```

Обратная связь остаётся данными для выбора, а не внешним приказом.

### Дельта P08

```text
SP-S1-P08:
реконструкция конкретного автоматического эпизода

SP-S2-P08:
следующая позиция = обратная связь о сценарной организации

SP-S3-P08:
следующие позиции = данные,
позволяющие сохранять, восстанавливать
или пересматривать собственную выбранную задачу
```

### Три объекта возможной корректировки

```text
1. управляющее присутствие задачи
2. способ решения задачи
3. сама задача
```

### Связь с HCM

| Положение | Влияние на SP-S3-P08 |
|---|---|
| SP-HCM-05 | реальные действия меняют ситуацию и самого действующего; оценке подлежит траектория, а не декларация |
| SP-HCM-06 | обратная связь используется для корректировки следующего цикла |
| SP-HCM-07 | выбранная задача может требовать повторного восстановления |
| SP-HCM-08 | устойчивость формируется повторяющимися циклами; один исход не является вердиктом |
| SP-HCM-09 | сохранение или смена задачи не гарантируют внешний результат |

### Связь с визуальными моделями

SP-VM-01: последовательность реальных ходов и следующих позиций даёт данные о том, формируется ли выбранная линия и требует ли коррекции задача или способ.

SP-VM-02: Пространство 2 не является доказательством полезности задачи; фактическая следующая позиция остаётся независимым источником обратной связи.

Особенно применимы SP-RISK-001, SP-RISK-002, SP-RISK-005, SP-RISK-007, SP-RISK-008, SP-RISK-014, SP-RISK-016, SP-RISK-019, SP-RISK-020, SP-RISK-023, SP-RISK-025 и SP-RISK-029.

Нового общего риска, термина или визуальной модели P08 не вводит.
