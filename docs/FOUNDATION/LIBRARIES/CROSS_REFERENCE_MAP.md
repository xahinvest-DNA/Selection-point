# Карта перекрёстных связей Selection Point

**Статус:** действующая навигационная библиотека  
**Дата обновления:** 19 августа 2026 года

Карта показывает, какие утверждения являются основанием для следующих элементов и где искать полный смысл.

---

## Сквозная последовательность

```text
SP-HCM-01–SP-HCM-09
→ SP-S1-P01–SP-S1-P13
→ SP-S2-P01–SP-S2-P13
→ SP-S3-P01
→ SP-S3-P02
→ SP-S3-P03
→ SP-S3-P04
```

Ступень 1 содержательно завершена. Ступень 2 содержательно завершена. Ступень 3 активна.

---

## Переход от Ступени 2 к Ступени 3

```text
сценарий перестаёт быть единственным организатором
→ антисценарий не должен закрыть открытый вопрос
→ SP-S3-P01:
  внутренняя рекомендация ≠ решение
→ SP-S3-P02:
  внешний факт ≠ автоматически заданный смысл и единственное продолжение
→ SP-S3-P03:
  текущий образ себя ≠ окончательная сущность и обязательное будущее
→ SP-S3-P04:
  человек начинает участвовать в выборе задачи,
  относительно которой организуются следующие ходы
```

Ключевое различение перехода:

```text
освобождение от обязательности сценария
≠ сформированная собственная задача

способность не подчиниться задаче
≠ способность сознательно организовывать несколько циклов другой задачей
```

## SP-SRC-001 и Ступень 3

SP-SRC-001 — «Как мысль становится материальной» — остаётся приоритетным первичным источником:

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Связи:

- мысль / модель → SP-HCM-01, SP-S3-P01–P04;
- внимание → SP-HCM-01, SP-S3-P04;
- состояние → SP-HCM-02, SP-S3-P01, SP-S3-P04;
- образ себя → SP-HCM-04, SP-S3-P03–P04;
- поле выбора → SP-HCM-04, SP-HCM-07, SP-S3-P04;
- действие / бездействие → SP-HCM-05, SP-HCM-09, SP-S3-P02–P04;
- ответ среды → SP-HCM-06, SP-S3-P02, SP-S3-P04;
- следующая позиция → SP-HCM-09, SP-S3-P01–P04, SP-VM-01, SP-VM-02;
- организация действий во времени → SP-HCM-08, SP-S3-P04.

SP-S3-P04 уточняет источник замкнутой петлёй:

```text
активная задача / модели
→ внимание
→ интерпретация
→ поле ходов
→ действие
→ независимый ответ среды
→ следующая позиция
→ обновление моделей и условий следующего цикла
```

Источник не становится каноном автоматически.

```text
действие = воздействие + исследование
```

## SP-S3-P03 — способ восприятия себя

**Полный источник:** `../FIVE_STAGES_THEORY/29_STAGE_3_SELF_PERCEPTION.md`  
**Канонический источник:** `../CANONICAL/21_STAGE_3_P03_CANONICAL.md`

```text
SP-S3-P02:
факт текущей позиции
не определяет единственное продолжение

→ SP-S3-P03:
факты обо мне
не определяют единственное продолжение меня
```

> **То, какой я сейчас, — факт моей текущей позиции, но не окончательный ответ на вопрос, кем я могу стать.**

> **Я не обязан сначала найти «настоящего себя», чтобы начать участвовать в том, кем становлюсь.**

> **Я не выбирал всё, из чего сформировался, но участвую в том, что формируется дальше.**

Связи с HCM:

| Положение | Влияние на SP-S3-P03 |
|---|---|
| SP-HCM-01 | образ себя является моделью, а не непосредственной сущностью |
| SP-HCM-04 | образ себя и сценарий участвуют в поле выбора, но могут быть различены как модели |
| SP-HCM-05 | действие изменяет не только ситуацию, но и действующего |
| SP-HCM-06 | последствия создают данные для уточнения модели себя |
| SP-HCM-08 | новые способности и правдоподобная модель себя формируются через повторяющиеся циклы |
| SP-HCM-09 | человек участвует в следующей позиции, не являясь автором всех обстоятельств и результатов |

## Утверждённый мост SP-S3-P03 → SP-S3-P04

**Полный источник:** `../FIVE_STAGES_THEORY/29A_STAGE_3_P03_TO_P04_INTERNAL_TASK_ADDENDUM.md`  
**Канонический источник:** `../CANONICAL/21A_STAGE_3_P03_TO_P04_INTERNAL_TASK_ADDENDUM.md`

Ключевое различение:

> **Внутренняя задача может активироваться и стать доминирующей без осознанного решения человека.**

> **Созидательная внутренняя задача — сознательно принятый человеком организатор последовательности выборов.**

Мост отделяет P03 «кто я» от P04 «что организует решение» и не канонизирует термин «метапрограмма».

## SP-S3-P04 — что управляет решениями

**Полный источник:** `../FIVE_STAGES_THEORY/30_STAGE_3_DECISION_DRIVERS.md`  
**Канонический источник:** `../CANONICAL/22_STAGE_3_P04_CANONICAL.md`

Каноническая формула:

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

Дополнительные формулы:

> **Заявленная цель говорит, чего я хочу. Внутренняя задача проявляется в том, что реально начинает организовывать мои решения.**

> **Свобода становится созидательной, когда человек способен не только отказаться от автоматической задачи, но и принять задачу, которая начинает организовывать его следующие ходы.**

### Связь P01 → P04

```text
P01:
внутренний голос не имеет автоматического права решения

→ P04:
одна из внутренних задач может быть сознательно принята
как организатор нескольких следующих циклов
```

### Связь P02 → P04

```text
P02:
реальность сохраняет независимость
и не гарантирует представленное продолжение

→ P04:
созидательная задача организует участие,
но не требует от среды гарантированного результата
```

### Связь P03 → P04

```text
P03:
образ себя является корректируемой моделью

→ P04:
результаты организованных задачей циклов
становятся данными,
способными изменять модель себя и убеждения
```

### Связи с HCM

| Положение | Влияние на SP-S3-P04 |
|---|---|
| SP-HCM-01 | убеждения и интерпретации рассматриваются как модели, а не готовая реальность |
| SP-HCM-02 | состояние влияет на то, какая задача и какие ходы получают психологический вес |
| SP-HCM-04 | образ себя и сценарий участвуют в доступности задач и действий |
| SP-HCM-05 | действие меняет ситуацию и действующего, создавая данные следующего цикла |
| SP-HCM-06 | обратная связь способна подтверждать, ослаблять или перестраивать модели |
| SP-HCM-07 | задача не отменяет множественность участков восстановления выбора |
| SP-HCM-08 | созидательная задача становится значимой как организатор нескольких повторяющихся циклов |
| SP-HCM-09 | задача организует участие, но не контролирует внешний результат |

### Уровни задачи

```text
оперативная задача
→ что нужно получить / прекратить / сохранить сейчас

сценарная задача
→ какую знакомую роль и определённость нужно воспроизвести

внутренняя задача
→ фактически действующий организатор приоритета

созидательная внутренняя задача
→ сознательно принятый организатор нескольких циклов
```

### Убеждение, цель и задача

```text
убеждение
≠ внутренняя задача

заявленная цель
≠ фактически действующая задача

ценность
≠ внутренняя задача

желание
≠ автоматически принятая задача
```

Убеждение формирует часть карты ожиданий; задача задаёт функциональный критерий, относительно которого данные и ходы получают приоритет.

### Замкнутый контур P04

```text
текущая позиция + состояние + модели + внешний контекст
→ активная внутренняя задача
→ направление внимания
→ значимые данные
→ интерпретация
→ ожидание
→ воспринимаемое поле ходов
→ решение
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ интерпретация обратной связи
→ изменение моделей / способностей / условий следующего цикла
```

Контур не является линейным детерминизмом: убеждения и состояние влияют на задачу, задача — на внимание, обратная связь — на модели, а повторение — на способности.

## Связь SP-S3-P04 с визуальными моделями

### SP-VM-01

Для P04 граф читается как:

```text
текущая позиция
→ задача организует критерий выбора
→ доступный ход
→ независимая следующая позиция
→ обратная связь
→ следующий цикл
```

Несколько циклов, организованных одной принятой задачей, могут начать формировать собственную линию, но не гарантируют конкретного внешнего результата.

### SP-VM-02

Созидательная внутренняя задача может использовать Пространство 2 как представленное направление или критерий, но:

```text
задача
≠ Пространство 2

Пространство 2
≠ гарантированный результат

фактическая следующая позиция
остаётся независимым ответом реальности
```

Новая визуальная модель для SP-S3-P04 не утверждалась.

## Связь SP-S3-P04 с рисками

Особенно значимы существующие риски:

- SP-RISK-002 — иллюзия полного контроля;
- SP-RISK-007 — подмена профессиональной помощи;
- SP-RISK-008 — бесконечный самоанализ;
- SP-RISK-010 — новая статусная идентичность;
- SP-RISK-014 — универсальный скрытый мотив;
- SP-RISK-016 — интеллектуальное понимание как изменение;
- SP-RISK-019–020 — ложная равная доступность и отрицание реальных ограничений;
- SP-RISK-023 — требование более поздних способностей слишком рано;
- SP-RISK-025 — система или AI выполняет способность вместо человека;
- SP-RISK-026 — объяснение становится новой автоматической петлёй.

Для SP-S3-P04 эти риски конкретизируются: нельзя назначать «настоящую внутреннюю задачу» извне, считать сознательную формулировку доказательством управляющего приоритета, превращать задачу в одержимость или использовать функциональную модель как достаточное объяснение зависимости и иных клинических состояний.

Нового общего риска отдельным ID не вводилось.
