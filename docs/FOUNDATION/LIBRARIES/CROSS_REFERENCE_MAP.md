## Системный предохранитель

SP-S3-P13:

> **Модель остаётся рабочей только пока реальность сохраняет возможность её изменить.**

Он сохраняется в P01–P05 четвёртой ступени: ни натренированный навык, ни быстрая рабочая модель, ни self-модель, ни выбранная задача, ни конкретный ход не получают иммунитета от фактической позиции.

## Ступень 3 → Ступень 4

### SP-S3-P12 → SP-S4-P01

```text
способность повторяемо доступна
в обычной вариативности
≠
способность одинаково доступна
под существенной нагрузкой
```

### SP-S3-P13 → SP-S4-P02

```text
модель должна оставаться корректируемой
→ под нагрузкой это требование сохраняется
даже для быстрого распознавания
```

### SP-S3-P03 → SP-S4-P03

```text
образ себя является корректируемой моделью
→ под нагрузкой различение может сохраняться интеллектуально,
но self-модель всё равно получать практически значимый вес
```

### SP-S3-P04 → SP-S4-P04

```text
я способен сознательно принять внутреннюю задачу
→ под нагрузкой необходимо сохранять её осознанное место
в иерархии решений без превращения в ригидный приказ
```

### SP-S3-P05 → SP-S4-P05

```text
я могу выбирать,
для чего совершается следующий ход
→ под нагрузкой выбранное направление
не должно автоматически схлопываться
в один субъективно обязательный ход
```

## Связи SP-S4-P05

P05 защищает переход:

```text
текущая позиция
→ выбранное направление
→ следующий доступный ход
```

от скрытой подмены:

```text
выбранное направление
=
единственный возникший ход
```

Основные связи:

```text
SP-S1-P05
точка выбора = функциональное окно участия,
а не одна секунда

SP-S2-P05
ход не обязан подтверждать сценарную роль

SP-S3-P05
человек способен выбирать назначение следующего хода

SP-S4-P01
нагрузка меняет доступность способности

SP-S4-P02
нагрузка меняет доступную рабочую картину
и вес данных

SP-S4-P04
значимое направление может сохраняться,
даже когда поле способов движения сужается

SP-S3-P13
фактическая позиция сохраняет право
изменить конкретный ход
```

Ключевые различения:

```text
выбранное направление
≠ единственный воспринимаемый ход

объективное ограничение реальности
≠ субъективное схлопывание поля под нагрузкой

можно представить альтернативу
≠ альтернатива practically available сейчас
```

Граница будущих параметров:

- P08 — навык восстановления / расширения поля;
- P09 — телесные и перцептивные проявления;
- P11 — практики, включая возможную проверку работы с периферическим зрением.

Delta: `S4_P05_AVAILABLE_POINT_OF_CHOICE_DELTA.md`.

## Простое ядро

SP-SRC-011:

```text
позиция
→ направление
→ ход
→ новая позиция

```
