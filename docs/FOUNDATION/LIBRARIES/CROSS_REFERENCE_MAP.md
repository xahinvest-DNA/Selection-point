# Карта перекрёстных связей Selection Point

**Статус:** действующая навигационная библиотека  
**Дата обновления:** 19 августа 2026 года

Карта показывает, какие утверждения являются основанием для следующих элементов и где искать полный смысл. Она является производным навигационным слоем и не заменяет полную теорию и канон.

---

## Сквозная последовательность

```text
SP-HCM-01–SP-HCM-09
→ SP-S1-P01–SP-S1-P13
→ SP-S2-P01–SP-S2-P13
→ SP-S3-P01
→ SP-S3-P02
→ SP-S3-P03
→ SP-S3-P04
→ SP-S3-P05
→ SP-S3-P06
→ SP-S3-P07
```

Ступень 1 содержательно завершена. Ступень 2 содержательно завершена. Ступень 3 активна.

## Переход от Ступени 2 к Ступени 3

```text
сценарий перестаёт быть единственным организатором
→ антисценарий не должен закрыть открытый вопрос
→ SP-S3-P01:
  внутренняя рекомендация ≠ решение
→ SP-S3-P02:
  внешний факт ≠ автоматически заданный смысл и единственное продолжение
→ SP-S3-P03:
  текущий образ себя ≠ окончательная сущность и обязательное будущее
→ SP-S3-P04:
  человек начинает участвовать в выборе задачи,
  относительно которой организуются следующие ходы
→ SP-S3-P05:
  различённая задача перестаёт автоматически обладать
  правом организовывать продолжение;
  критерий следующего хода может быть сохранён,
  уточнён или сознательно изменён
→ SP-S3-P06:
  сознательный выбор задачи не принимается
  за уже сформированную устойчивую систему поведения
→ SP-S3-P07:
  реальный, но ещё неустойчивый выбор
  может переживаться как невозможность
  надёжно опираться на самого себя
```

Ключевые различения перехода:

```text
освобождение от обязательности сценария
≠ сформированная собственная задача

способность не подчиниться сценарной задаче
≠ способность сознательно принять другую задачу

сформулировать новую задачу
≠ передать ей критерий приоритета следующего хода

сознательно выбрать задачу
≠ сформировать её устойчивый управляющий приоритет

неустойчивость выбранной линии
≠ нереальность сделанного выбора
```

## SP-SRC-001 и Ступень 3

SP-SRC-001 — «Как мысль становится материальной» — остаётся приоритетным первичным источником:

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Связи:

- мысль / модель → SP-HCM-01, SP-S3-P01–P07;
- внимание → SP-HCM-01, SP-S3-P04–P07;
- состояние → SP-HCM-02, SP-S3-P01, SP-S3-P04–P07;
- образ себя → SP-HCM-04, SP-S3-P03–P07;
- поле выбора → SP-HCM-04, SP-HCM-07, SP-S3-P04–P07;
- действие / бездействие → SP-HCM-05, SP-HCM-09, SP-S3-P02–P07;
- ответ среды → SP-HCM-06, SP-S3-P02, SP-S3-P04–P07;
- следующая позиция → SP-HCM-09, SP-S3-P01–P07, SP-VM-01, SP-VM-02;
- организация действий во времени → SP-HCM-08, SP-S3-P04–P07.

SP-S3-P04 уточняет источник замкнутой петлёй:

```text
активная задача / модели
→ внимание
→ интерпретация
→ поле ходов
→ действие
→ независимый ответ среды
→ следующая позиция
→ обновление моделей и условий следующего цикла
```

SP-S3-P05 добавляет точку повторного участия:

```text
активная задача
→ задача становится различимой
→ функциональное окно выбора
→ сохранить / уточнить задачу
  или сознательно принять другую
→ изменённый критерий следующего хода
```

SP-S3-P06 добавляет временную границу между выбором и формированием:

```text
сознательно принятая задача
→ может изменить следующий ход
→ но устойчивое управляющее присутствие
  проверяется и формируется
  через реальные циклы и обратную связь
```

SP-S3-P07 добавляет субъективное противоречие этого процесса:

```text
выбор задачи реален
→ устойчивость ещё неполна
→ прежняя или конкурирующая задача
  снова получает приоритет
→ человек может принять это
  за ненадёжность собственного выбора
```

Источник не становится каноном автоматически.

## SP-S3-P04 — что управляет решениями

**Полный источник:** `../FIVE_STAGES_THEORY/30_STAGE_3_DECISION_DRIVERS.md`  
**Канонический источник:** `../CANONICAL/22_STAGE_3_P04_CANONICAL.md`

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

> **Заявленная цель говорит, чего я хочу. Внутренняя задача проявляется в том, что реально начинает организовывать мои решения.**

> **Свобода становится созидательной, когда человек способен не только отказаться от автоматической задачи, но и принять задачу, которая начинает организовывать его следующие ходы.**

### Основной контур P04

```text
текущая позиция + состояние + модели + внешний контекст
→ активная внутренняя задача
→ внимание
→ значимые данные
→ интерпретация
→ поле ходов
→ решение
→ действие / бездействие
→ ответ среды
→ фактическая следующая позиция
→ обратная связь
→ изменение моделей / способностей / условий следующего цикла
```

## SP-S3-P05 — доступная точка выбора

**Полный источник:** `../FIVE_STAGES_THEORY/31_STAGE_3_AVAILABLE_POINT_OF_CHOICE.md`  
**Канонический источник:** `../CANONICAL/23_STAGE_3_P05_CANONICAL.md`

> **Я могу выбрать, для чего будет сделан следующий ход.**

> **Мне не обязательно продолжать решать ту задачу, которая сейчас стала главной. Я могу выбрать, какую задачу будет решать мой следующий ход.**

```text
SP-S1-P05:
я могу изменить следующий ход

SP-S2-P05:
следующий ход не обязан доказывать,
кто я

SP-S3-P05:
я могу выбирать,
для чего вообще совершается следующий ход
```

Функциональное окно P05 существует там, где действующая задача уже достаточно различима, а продолжение ещё может быть организовано относительно сохранённой, уточнённой или другой сознательно принятой задачи.

```text
изменить действие
≠ изменить задачу

сформулировать новую задачу
≠ передать ей критерий приоритета следующего хода

выбор задачи
≠ выбор гарантированного результата
```

## SP-S3-P06 — главная иллюзия

**Полный источник:** `../FIVE_STAGES_THEORY/32_STAGE_3_MAIN_ILLUSION.md`  
**Канонический источник:** `../CANONICAL/24_STAGE_3_P06_CANONICAL.md`

> **Я выбрал задачу — значит теперь я действую из неё.**

> **Выбор задачи начинает новую линию, но ещё не создаёт устойчивую систему.**

> **Выбрать задачу — не значит закончить выбирать.**

```text
задача сознательно выбрана
≠
задача получила устойчивый управляющий приоритет
```

```text
один согласованный ход
≠ устойчивая система

один несогласованный ход
≠ отсутствие сделанного выбора
```

SP-S3-P06 связывает P05 со SP-HCM-08: акт выбора может причинно изменить следующий цикл, но устойчивость формируется повторением, обратной связью и изменением реальной системы будущих решений.

## SP-S3-P07 — главная боль

**Полный источник:** `../FIVE_STAGES_THEORY/33_STAGE_3_MAIN_PAIN.md`  
**Канонический источник:** `../CANONICAL/25_STAGE_3_P07_CANONICAL.md`

Главная формула:

> **Я действительно выбрал — и всё равно не могу на себя опереться.**

Дополнительная формула:

> **Почему мне снова приходится выбирать то, что я уже выбрал?**

Корректирующая граница:

> **Неустойчивость выбора не доказывает его нереальность; она показывает, что выбранная линия ещё формируется.**

### Дельта P07

```text
SP-S1-P07:
мои ходы снова ведут меня не туда

SP-S2-P07:
моё понимание не удерживает меня вне сценария

SP-S3-P07:
мой собственный выбор ещё не становится
надёжной системой, на которую я могу опереться
```

### Связь P06 → P07

```text
P06:
я ошибочно принимаю акт выбора
за уже сформированную устойчивость

→ P07:
когда реальность показывает отсутствие
автоматической устойчивости,
расхождение переживается как
ненадёжность собственного выбора
```

### Центральные различения

```text
выбор есть
≠ устойчивость уже сформирована

один несогласованный ход
≠ отсутствие сделанного выбора

повторный выбор
≠ возвращение в исходную точку

коррекция задачи по обратной связи
≠ неспособность удерживать выбор
```

Последовательность:

```text
B → B → A → B → A → B → B → B
```

может уже быть иной траекторией, чем непрерывное `A → A → A`, даже если выбранная линия ещё не стала устойчивой.

При этом повторяющееся отсутствие управляющего присутствия B остаётся данными и не должно защищаться одной декларацией задачи.

### Связь с HCM

| Положение | Влияние на SP-S3-P07 |
|---|---|
| SP-HCM-02 | разные состояния могут менять психологическую доступность выбранного продолжения |
| SP-HCM-05 | каждый реальный ход участвует в формировании следующей конфигурации |
| SP-HCM-06 | фактическая траектория и последствия являются данными, а не приговором личности |
| SP-HCM-07 | выбранная задача может требовать повторного восстановления в новых циклах |
| SP-HCM-08 | повторное восстановление не равно началу с нуля; конфигурация формируется накопительно |
| SP-HCM-09 | устойчивость внутренней задачи не гарантирует внешний результат |

### Связь с визуальными моделями

SP-VM-01 показывает, что траектория может изменяться ещё до полной устойчивости; единичный возврат не определяет весь граф будущих ходов.

SP-VM-02 сохраняет фактическую следующую позицию как источник данных: неполучение ожидаемого результата не доказывает нереальность выбора.

Особенно применимы SP-RISK-001, SP-RISK-002, SP-RISK-005, SP-RISK-007, SP-RISK-008, SP-RISK-010, SP-RISK-014, SP-RISK-016, SP-RISK-019, SP-RISK-020, SP-RISK-021, SP-RISK-023 и SP-RISK-025.

Нового общего риска отдельным ID не вводилось.
