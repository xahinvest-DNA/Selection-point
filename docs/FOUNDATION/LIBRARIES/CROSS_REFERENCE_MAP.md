# Карта перекрёстных связей Selection Point

**Статус:** действующая навигационная библиотека  
**Дата обновления:** 18 августа 2026 года

Карта показывает, какие утверждения являются основанием для следующих элементов и где искать полный смысл.

## Переход от Ступени 1 к Ступени 2

```text
несколько отдельно реконструированных эпизодов
→ эпизоды сохранены как сопоставимые единицы
→ человек замечает, что некоторые повторения не случайны
→ внешнее сходство ещё смешивается с функциональной организацией
→ SP-S2-P01
```

SP-S1-P12 передаёт второй ступени сопоставимый материал. SP-S1-P13 защищает от ярлыка, объяснения и превосходства вместо участия.

## Внутренняя последовательность Ступени 2

```text
SP-S2-P01

но функциональная организация ещё неполно различена

→ SP-S2-P02
сценарий воспринимается как то,
что снова происходит с человеком

→ SP-S2-P03
повторяющаяся роль становится сценарной идентичностью

→ SP-S2-P04
сценарная задача определяет,
что необходимо сохранить, доказать или не допустить

→ SP-S2-P05
сценарная задача перестаёт быть приказом реальности

→ SP-S2-P06
противоположность прошлому ошибочно принимается
за самостоятельно выбранное направление

→ SP-S2-P07
возврат переживается как доказательство невозможности свободы

→ SP-S2-P08
фактическая следующая позиция используется как обратная связь

→ SP-S2-P09
становится различимой повторяющаяся телесная организация

→ SP-S2-P10
становится различимой повторяющаяся функциональная жизненная позиция

→ SP-S2-P11
гипотеза, ход, следующая позиция и корректировка
образуют проверяемый цикл

→ SP-S2-P12
цикл становится повторяемо доступным;
сценарий перестаёт быть единственным организатором,
а вопрос о собственной задаче становится практически доступным

→ SP-S2-P13
различается ловушка антисценария:
новая идентичность, цель и действия
снова строятся вокруг обязанности доказать освобождение
```

Ступень 2 содержательно завершена.

## Переход от Ступени 2 к Ступени 3

Критический мост образуют SP-S2-P12 и SP-S2-P13.

```text
сценарная гипотеза становится проверяемой
→ следующий ход не обязан доказывать роль
→ фактическая следующая позиция используется как обратная связь
→ сценарий перестаёт быть единственным организатором следующего цикла
→ вопрос о собственной задаче становится практически доступным
→ антисценарий различается как ложное закрытие этого вопроса
→ SP-S3-P01
```

Ключевое различение перехода:

```text
освобождение от обязательности сценария
≠ сформированная собственная задача
```

## SP-SRC-001 и переход к Ступени 3

SP-SRC-001 — «Как мысль становится материальной» — зарегистрирован как приоритетный первичный источник и должен учитываться при разработке Ступени 3.

Связь с архитектурой:

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

| Элемент источника | Связанные утверждения Selection Point |
|---|---|
| мысль / модель | SP-HCM-01, SP-S1-P02, SP-S2-P02 |
| состояние | SP-HCM-02, SP-S1-P09, SP-S2-P09 |
| поле выбора | SP-HCM-04, SP-HCM-07, SP-S1-P05, SP-S2-P05 |
| действие / бездействие | SP-HCM-05, SP-HCM-09 |
| ответ среды и последствия | SP-HCM-06, SP-S2-P08, SP-VM-01 |
| следующая позиция | SP-HCM-09, SP-S2-P08, SP-S3-P01, SP-VM-01, SP-VM-02 |
| организация действий во времени | SP-HCM-08, SP-S3-P01 и будущая архитектура Ступени 3 |

SP-SRC-001 не становится каноном автоматически. Он задаёт источник для дальнейшего обсуждения, а не готовое содержание следующих параметров.

## SP-S3-P01 — внутренние связи

**Полный источник:** `../FIVE_STAGES_THEORY/27_STAGE_3_STATE.md`  
**Канонический источник:** `../CANONICAL/19_STAGE_3_P01_CANONICAL.md`

Центральная связь:

```text
SP-S2-P12
сценарий перестаёт быть единственным организатором

+ SP-S2-P13
антисценарий не должен закрыть открытый вопрос

+ SP-SRC-001
мысль становится материально значимой через реальные причинные звенья

→ SP-S3-P01
отдельные свободные ходы уже возможны,
но собственная устойчивая линия ещё не сформирована
```

Короткая формула SP-S3-P01:

> **Мне уже не обязательно жить из прежнего сценария — но я ещё не знаю, что будет организовывать мои действия вместо него.**

Утверждённое переходное различение:

> **Внутренний голос имеет рекомендательный характер. Услышать рекомендацию — ещё не значит принять решение.**

Полная методическая формулировка:

> **Любая возникшая внутри мысль, импульс, интерпретация или требование может быть принята к рассмотрению, но не обладает автоматическим правом определять следующий ход.**

Главные связи:

```text
внутренняя рекомендация
→ данные для рассмотрения
≠ готовое решение

сценарий не обязателен
→ дополнительное пространство выбора
≠ готовая внутренняя задача

отдельный свободный ход
→ новая фактическая позиция
≠ устойчивая собственная траектория
```

## Связь SP-S3-P01 с визуальными моделями

### SP-VM-01 — граф траекторий выбора

Для SP-S3-P01 модель показывает:

- отдельный доступный ход создаёт следующую позицию;
- несколько отдельных ходов могут вести по разным ветвям;
- наличие иной ветви ещё не означает существование устойчивой выбранной линии;
- фактическая последовательность возникает только через реальные ходы и последствия.

### SP-VM-02 — Пространство 1, Пространство 2 и фактическая следующая позиция

Для SP-S3-P01 модель помогает удерживать:

- отсутствие готовой внутренней задачи не требует немедленно создавать обязательное Пространство 2;
- образ возможного будущего не равен фактической следующей позиции;
- возможное будущее не является гарантией результата;
- дальнейшая внутренняя задача не должна определяться как средство отменить текущее Пространство 1.

Новая визуальная модель для SP-S3-P01 не утверждалась.

## Связь SP-S3-P01 с рисками

Особенно значимы ранее утверждённые риски:

- SP-RISK-002 — иллюзия полного контроля;
- SP-RISK-007 — подмена помощи профессиональной помощью системой;
- SP-RISK-008 — бесконечный самоанализ;
- SP-RISK-010 — новая статусная идентичность;
- SP-RISK-014 — универсальный скрытый мотив;
- SP-RISK-016 — интеллектуальное понимание как изменение;

SP-S3-P01 нового общего риска не вводит, но уточняет применение существующих рисков к теме неопределённости, внутреннего голоса и будущей внутренней задачи.

## Текущая последовательность проекта

```text
SP-HCM-01–SP-HCM-09
→ SP-S1-P01–SP-S1-P13
→ SP-S2-P01–SP-S2-P13
→ SP-S3-P01
```

> **SP-S3-P01 утверждён; SP-S3-P02 не открыт.**

> **Как человек воспринимает реальность, когда сценарий уже не обладает автоматическим правом организовывать следующий ход, а собственная устойчивая внутренняя задача ещё не сформирована?**
