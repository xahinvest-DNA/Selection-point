# Карта перекрёстных связей Selection Point

**Статус:** действующая навигационная библиотека  
**Дата обновления:** 18 августа 2026 года

Карта показывает, какие утверждения являются основанием для следующих элементов и где искать полный смысл.

---

## Сквозная последовательность

```text
SP-HCM-01–SP-HCM-09
→ SP-S1-P01–SP-S1-P13
→ SP-S2-P01–SP-S2-P13
→ SP-S3-P01
→ SP-S3-P02
→ SP-S3-P03
```

Ступень 1 содержательно завершена. Ступень 2 содержательно завершена. Ступень 3 активна.

---

## Переход от Ступени 2 к Ступени 3

```text
сценарий перестаёт быть единственным организатором
→ антисценарий не должен закрыть открытый вопрос
→ SP-S3-P01:
  внутренняя рекомендация ≠ решение
→ SP-S3-P02:
  внешний факт ≠ автоматически заданный смысл и единственное продолжение
→ SP-S3-P03:
  текущий образ себя ≠ окончательная сущность и обязательное будущее
```

Ключевое различение:

```text
освобождение от обязательности сценария
≠ сформированная собственная задача
```

## SP-SRC-001 и Ступень 3

SP-SRC-001 — «Как мысль становится материальной» — остаётся приоритетным первичным источником:

```text
мысль
→ внимание
→ воспринятая модель
→ ожидание и состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Связи:

- мысль / модель → SP-HCM-01, SP-S3-P01–P03;
- действие / бездействие → SP-HCM-05, SP-HCM-09, SP-S3-P02–P03;
- ответ среды → SP-HCM-06, SP-S3-P02;
- следующая позиция → SP-HCM-09, SP-S3-P01–P03, SP-VM-01, SP-VM-02;
- организация действий во времени → SP-HCM-08 и будущие параметры Ступени 3.

Источник не становится каноном автоматически.

## SP-S3-P03 — способ восприятия себя

**Полный источник:** `../FIVE_STAGES_THEORY/29_STAGE_3_SELF_PERCEPTION.md`  
**Канонический источник:** `../CANONICAL/21_STAGE_3_P03_CANONICAL.md`

Центральная связь:

```text
SP-S3-P02:
факт текущей позиции
не определяет единственное продолжение

→ SP-S3-P03:
факты обо мне
не определяют единственное продолжение меня
```

Короткие формулы:

> **То, какой я сейчас, — факт моей текущей позиции, но не окончательный ответ на вопрос, кем я могу стать.**

> **Я не обязан сначала найти «настоящего себя», чтобы начать участвовать в том, кем становлюсь.**

> **Я не выбирал всё, из чего сформировался, но участвую в том, что формируется дальше.**

Связи с HCM:

| Положение | Влияние на SP-S3-P03 |
|---|---|
| SP-HCM-01 | образ себя является моделью, а не непосредственной сущностью |
| SP-HCM-04 | образ себя и сценарий участвуют в поле выбора, но могут быть различены как модели |
| SP-HCM-05 | действие изменяет не только ситуацию, но и действующего |
| SP-HCM-06 | последствия создают данные для уточнения модели себя |
| SP-HCM-08 | новые способности и правдоподобная модель себя формируются через повторяющиеся циклы |
| SP-HCM-09 | человек участвует в следующей позиции, не являясь автором всех обстоятельств и результатов |

Ключевые различения:

```text
я не фиксирован прошлым
≠ прошлое не имеет последствий

идентичность не окончательна
≠ идентичность произвольна

я могу изменяться
≠ я могу мгновенно стать кем угодно

новая декларация идентичности
≠ сформированная способность
```

## Мост SP-S3-P03 → SP-S3-P04

Авторское дополнение Андрея:

```text
целенаправленные размышления / внимание
→ убеждения
→ организация поведения
→ действия
→ результаты
→ новые точки отсчёта для внимания и размышления
```

Решение о размещении:

- SP-S3-P03 использует только часть, относящуюся к самовосприятию: убеждения о себе являются частью корректируемой модели себя и могут участвовать в организации поведения;
- полный цикл относится к SP-S3-P04 «Что управляет решениями»;
- термин «метапрограмма» не канонизирован до отдельного определения и проверки;
- P04 должен проверить не только направление «убеждение → поведение», но и обратные связи: результат может укреплять, ослаблять или перестраивать убеждение через внимание, интерпретацию и новые данные.

## Связь с визуальными моделями

### SP-VM-01

Для SP-S3-P03 граф показывает:

```text
текущая конфигурация
→ доступный ход
→ действие
→ следующая позиция
→ повторение
→ изменение реальной способности
→ уточнение модели себя
```

Один иной ход не доказывает новую идентичность; повторяющиеся циклы создают фактическое основание для изменения модели себя.

### SP-VM-02

Текущий образ себя относится к фактам и моделям Пространства 1, но не определяет всё будущее. Представление «каким я стану» относится к Пространству 2 и не является гарантией фактического становления.

Новая визуальная модель для SP-S3-P03 не утверждалась.

## Связь с рисками

Особенно значимы существующие риски:

- SP-RISK-002 — иллюзия полного контроля;
- SP-RISK-009–010 — иерархия человеческой ценности и новая статусная идентичность;
- SP-RISK-014 — универсальный скрытый мотив;
- SP-RISK-016 — интеллектуальное понимание как изменение;
- SP-RISK-019–020 — ложная равная доступность и отрицание реальных ограничений;
- SP-RISK-023 — требование более поздних способностей слишком рано;
- SP-RISK-025 — система или AI выполняет способность вместо человека;
- SP-RISK-026 — объяснение становится новой автоматической петлёй.

SP-S3-P03 нового общего риска не вводит.
