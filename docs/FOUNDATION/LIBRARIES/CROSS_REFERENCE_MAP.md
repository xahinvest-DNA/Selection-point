## Системный предохранитель

SP-S3-P13:

> **Модель остаётся рабочей только пока реальность сохраняет возможность её изменить.**

Этот принцип проходит через всю S4: ни навык, ни рабочая модель, ни self-модель, ни выбранная задача, ни конкретный ход, ни прежняя жизненная форма не получают иммунитета от фактической позиции.

## Связи SP-S4-P10

P10 собирает life-scale след предыдущих параметров:

```text
P04:
релевантный приоритет может сохраняться / пересматриваться

P05:
направление не равно одному обязательному ходу

P08:
участие может восстановиться из неполной доступности

P10:
несколько таких ходов
→ меняют распределение ресурсов / ролей / обязательств
→ создают новую фактическую жизненную форму
```

Главная вертикаль:

```text
S1-P10:
текущая жизнь как накопленная позиция

S2-P10:
разные обстоятельства — знакомая функциональная позиция

S3-P10:
собственная линия начинает оставлять материальный след

S4-P10:
устойчивость линии
не требует неизменности её прежней формы
```

Ключевые различения:

```text
сохранение формы
≠ сохранение траектории

изменение формы
≠ потеря траектории

сохранение направления
≠ persistence любой ценой
```

Prospective observability связывает P10 с HCM feedback loop:

```text
новая позиция признана
→ релевантный приоритет различим / пересмотрен
→ следующий ход выполним
→ feedback остаётся способным изменить продолжение
```
