## Системный предохранитель

SP-S3-P13 вводит сквозной принцип:

> **Модель остаётся рабочей только пока реальность сохраняет возможность её изменить.**

Связи:

```text
SP-HCM-01
воспринятая модель ≠ вся реальность

SP-HCM-06
обратная связь может менять следующий цикл

SP-HCM-09
создание продолжения ≠ контроль результата

SP-S3-P13
любая рабочая модель остаётся пересматриваемой

SP-S4-P01
автоматизированный навык не получает иммунитета от реальности

SP-S4-P02
быстрая рабочая модель не получает статуса истины
```

## Переход Ступень 1 → Ступень 2

```text
отдельный автоматический эпизод становится различим
→ повторения между эпизодами становятся видимыми
→ сценарий обнаруживается как организующая структура
```

Полные связи: канонические материалы Ступеней 1 и 2.

---

## Переход Ступень 2 → Ступень 3

```text
сценарий перестаёт быть единственным организатором
→ внутренняя рекомендация ≠ решение
→ фактическая позиция сохраняет неизвестность
→ образ себя становится корректируемой моделью
→ человек участвует в выборе задачи-организатора
→ выбор задачи ≠ устойчивая способность
→ способность формируется через действие и обратную связь
→ телесная и сознательная перестройка могут идти не одновременно
→ выбранная линия оставляет фактический след
→ практика начинает становиться способом участия
→ сама модель Selection Point остаётся пересматриваемой
```

```

```

## Governance-связи

С 28 августа 2026 года сама разработка Selection Point включена в тот же feedback-loop:

```text
architectural claim
→ observability check
→ external evidence / counterevidence
→ falsification pass
→ owner decision
→ canonical update
→ consequences for later architecture
→ revision when required
```

## Матрица 5 × 13

Связь между одинаковыми P-номерами разных ступеней больше не считается достаточным доказательством новой архитектурной дельты.

Перед каждым следующим параметром проверяется:

```text
есть функционально новое различение?
├─ да → новый parameter claim
├─ нет → zero-delta
└─ каркас мешает описанию → предложить пересмотр структуры
```
