# Общие библиотеки Selection Point

**Статус:** действующая инфраструктура канонического слоя  
**Дата введения:** 4 июля 2026 года  
**Дата обновления:** 19 августа 2026 года

## Состав

1. `TERMS_REGISTRY.md` — единые определения терминов со стабильными ID.
2. `CLAIMS_REGISTRY.md` — карта утверждённых положений и их источников.
3. `EXAMPLE_LIBRARY.md` — переиспользуемые примеры.
4. `RISKS_AND_BOUNDARIES.md` — централизованные риски и ограничения.
5. `EVIDENCE_MAP.md` — карта доказательного статуса.
6. `CROSS_REFERENCE_MAP.md` — связи между слоями архитектуры.

## Правила

- новый термин проверяется по `TERMS_REGISTRY.md`;
- утверждённый тезис получает стабильный ID в `CLAIMS_REGISTRY.md`;
- новый общий риск добавляется только при реальной архитектурной необходимости;
- внутренняя утверждённость не равна научной доказанности;
- после утверждения параметра обновляется `CROSS_REFERENCE_MAP.md`.

## Текущий охват

Библиотеки охватывают:

- SP-HCM-01–SP-HCM-09;
- SP-S1-P01–SP-S1-P13;
- SP-S2-P01–SP-S2-P13;
- SP-S3-P01–SP-S3-P06;
- SP-SRC-001 как приоритетный первичный источник;
- SP-VM-01 и SP-VM-02;
- риски SP-RISK-001–SP-RISK-029.

При утверждении SP-S3-P04 введены два общих термина:

- `SP-TERM-INTERNAL-TASK` — внутренняя задача;
- `SP-TERM-CREATIVE-INTERNAL-TASK` — созидательная внутренняя задача.

SP-S3-P05 и SP-S3-P06 новых общих терминов не вводят: они используют уже утверждённые понятия внутренней задачи, созидательной внутренней задачи, доступного хода, обратной связи и следующей позиции.

Нового универсального примера, нового общего риска или новой визуальной модели для SP-S3-P06 не вводилось.

Термин «метапрограмма» **не канонизирован**.

## Последняя архитектурная дельта

```text
SP-S3-P01:
внутренняя рекомендация
≠ готовое решение

SP-S3-P02:
внешний факт
≠ автоматически заданный смысл
≠ единственное продолжение

SP-S3-P03:
текущий образ себя
≠ окончательная сущность
≠ обязательное будущее

SP-S3-P04:
человек начинает участвовать
в выборе задачи,
относительно которой организуются следующие ходы

SP-S3-P05:
различённая задача
≠ обязательный организатор продолжения;
человек может сохранить, уточнить
или изменить задачу,
относительно которой выбирается следующий ход

SP-S3-P06:
сознательно выбранная задача
≠ уже сформированный устойчивый организатор поведения
```

Канонические формулы SP-S3-P06:

> **Я выбрал задачу — значит теперь я действую из неё.**

> **Выбор задачи начинает новую линию, но ещё не создаёт устойчивую систему.**

> **Выбрать задачу — не значит закончить выбирать.**

> **Выбор запускает формирование, но не является самим сформированным результатом.**

Различения:

```text
задача сознательно выбрана
≠ задача получила устойчивый управляющий приоритет

один согласованный ход
≠ устойчивая система

один несогласованный ход
≠ отсутствие сделанного выбора
```

P06 сохраняет SP-HCM-08: новая конфигурация формируется повторяющимися циклами, а не единичным решением. При этом устойчивость не требует постоянного сознательного удержания формулировки задачи.

## Действующая остановка

SP-S3-P06 утверждён.

SP-S3-P07 не открыт.
