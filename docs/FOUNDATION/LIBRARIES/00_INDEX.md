## Delta-first

После каждого нового утверждённого параметра большие общие реестры **не переписываются автоматически**.

Сначала создаётся parameter delta:

```text
новый claim
+ evidence questions
+ cross-reference
+ только реально новые terms / risks / visual decisions
```

Плановая консолидация больших реестров выполняется:

- после P05;
- после P10;
- после P13;
- на границе ступени;
- либо по отдельному решению Андрея.

28 августа 2026 года выполнена внеплановая governance-консолидация, которая привела `CLAIMS_REGISTRY.md`, `EVIDENCE_MAP.md` и `CROSS_REFERENCE_MAP.md` в соответствие с SP-S3-P13 и SP-S4-P01–P02.
