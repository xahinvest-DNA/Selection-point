# Реестр исходных материалов Selection Point

**Статус:** действующий реестр первичных материалов  
**Дата создания:** 30 июля 2026 года  
**Дата обновления:** 21 августа 2026 года  
**Назначение:** сохранять авторские диалоги, наблюдения, личный опыт, книги, исследовательские заметки и другие материалы, из которых развивается метод.

## Нормативный статус

Материалы этого раздела относятся к уровню исходных материалов в иерархии источников истины Selection Point.

Они:

- питают дальнейшую архитектуру метода;
- сохраняют исходный ход мысли без сокращения;
- могут иметь высокий методологический приоритет;
- не становятся каноническим положением автоматически;
- не изменяют утверждённую архитектуру без отдельного явного решения Андрея и полного цикла фиксации.

## Статусы приоритета

- **приоритетный первичный источник** — материал, на который необходимо опираться при разработке связанных положений;
- **приоритетный рабочий источник** — согласованная смысловая опора для разработки конкретного параметра, не становящаяся его каноном автоматически;
- **рабочий источник** — материал, содержащий полезные гипотезы, примеры или различения;
- **справочный источник** — материал для контекста и дальнейшей проверки;
- **архивный источник** — материал, сохраняемый как история развития проекта.

## Правило использования SP-SRC-001

```text
мысль
→ направление внимания
→ воспринятая модель ситуации
→ состояние
→ доступное поле выбора
→ действие или бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

Источник нельзя сводить к магической формуле «достаточно правильно подумать». Его смысл — в причинном участии мысли через реальные звенья поведения, среды, последствий и следующей позиции.

## Правило использования SP-SRC-002

```text
выбрать задачу
≠ доказать её полезность

устойчиво выполнять задачу
≠ обязательно развиваться
```

Задача остаётся открытой проверке через фактические циклы:

```text
выбор задачи
→ действие
→ фактическая следующая позиция
→ обратная связь
→ сохранить / восстановить / уточнить / изменить задачу
```

SP-SRC-002 не является самостоятельным каноном. Его утверждённые смысловые границы реализованы в SP-S3-P08.

Главная граница:

```text
телесный сигнал
= часть данных текущей позиции
≠ истина
≠ приказ
≠ отдельный арбитр правильного решения
```

## Правило использования SP-SRC-004

SP-SRC-004 остаётся исходным рабочим материалом и не заменяет утверждённый P10.

Его утверждённое архитектурное применение реализовано в SP-S3-P10 через контур:

```text
текущая фактическая позиция
+
выбранная внутренняя задача / направление
→ доступный следующий ход
→ действие / бездействие
→ независимый ответ среды
→ фактическая следующая позиция
→ обратная связь
→ сохранить / уточнить / изменить способ или задачу
```

Ключевые границы:

```text
решение проблемы
≠ создание

создание
≠ отрицание проблемы

создание
≠ полный контроль

не знать всю дорогу
≠ не иметь выбранного направления

направление без движения
≠ создаваемая траектория

бездействие
≠ сохранение неизменной позиции
```

Особенно важно:

> **Следующая позиция возникнет в любом случае. Вопрос не в том, будет ли она сформирована, а в том, насколько человек участвовал в направлении её формирования.**

Утверждённый полный источник P10: `../FIVE_STAGES_THEORY/36_STAGE_3_LIFE_MANIFESTATIONS.md`.

Каноническая карточка P10: `../CANONICAL/28_STAGE_3_P10_CANONICAL.md`.

## Правило использования SP-SRC-005

SP-SRC-005 является согласованной рабочей опорой перед открытием SP-S3-P12 и не является самим P12.

Ключевой рабочий переход:

```text
я знаю модель
→ вспоминаю практику
→ применяю её

постепенно

происходит жизнь
→ я различаю позицию
→ не свожу своё продолжение к внешней причине
→ выбираю доступное участие
→ возвращаюсь после отклонения
```

Ключевые границы:

```text
внешнее влияние реально
≠ внешний источник события полностью определяет моё продолжение

ответственность
≠ вина
≠ отрицание причинности среды

способность работает в упражнении
≠ способность перенеслась в жизнь

знать Selection Point
≠ практически обладать способностью выбора

обычная вариативность жизни
≠ крайнее напряжение четвёртой ступени
```

Формулы `«Я уже не обязан вспоминать систему, чтобы участвовать иначе»` и `«То, что раньше было практикой, начинает становиться способом жить»` являются формулами-кандидатами для обсуждения P12, а не утверждённым каноном.
