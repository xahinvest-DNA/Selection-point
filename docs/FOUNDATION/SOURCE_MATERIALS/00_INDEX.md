## Использование источников

### Общий принцип

```text
source material
→ архитектурная гипотеза
→ Architect pass
→ Reality Check / counterevidence
→ Red Team / falsification
→ явное решение владельца
→ full theory + canonical + delta
```

Исходный материал не получает статус доказательства только потому, что он личный, убедительный или согласуется с книгами.

### Телесные сигналы

```text
телесный сигнал
= данные текущей позиции
≠ приказ
≠ доказательство истинности интерпретации
```

### Выбранное направление

```text
направление
≠ конкретный ход
```

Эта граница получила отдельную утверждённую форму в SP-S4-P04 и SP-S4-P05.

### SP-S4-P05

Architect pass P05 включал личное наблюдение о напряжении лба, субъективном туннельном зрении и расширении воспринимаемого поля при намеренном включении периферического зрения.

Эти элементы сохраняются как pilot signals и материал будущих P09/P11, но **не являются каноническим определением P05**.

Утверждённый P05:

- `../FIVE_STAGES_THEORY/44_STAGE_4_AVAILABLE_POINT_OF_CHOICE.md`;
- `../CANONICAL/36_STAGE_4_P05_CANONICAL.md`;
- `../LIBRARIES/S4_P05_AVAILABLE_POINT_OF_CHOICE_DELTA.md`;
- `../GOVERNANCE/RC-009_SP-S4-P05.md`.

Каноническая короткая формула:

> **Выбранное направление ≠ единственный воспринимаемый ход.**
