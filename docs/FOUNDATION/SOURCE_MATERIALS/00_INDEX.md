**Статус:** действующий реестр первичных материалов

## Нормативный статус

Исходные материалы питают архитектуру, но не становятся каноном автоматически. Приоритет имеют последнее явное решение владельца и утверждённые full theory / canonical sources.

Статусы:

- приоритетный первичный источник;
- приоритетный рабочий источник;
- рабочий / исследовательский источник;
- справочный источник;
- архивный источник.

### SP-SRC-011 — «Простое ядро Selection Point и стратегия завершения архитектуры»

- файл: `11_2026-08-29_CORE_LOOP_AND_COMPLETION_STRATEGY.md`;
- дата диалога: 29 августа 2026 года;
- статус: приоритетный первичный источник + явное решение владельца о порядке дальнейшей разработки;
- связи: простое ядро, anti-complexity rule, завершение текущей архитектуры перед Whole-System Review, разработка SP-S4-P05;
- рабочее ядро:

```text
увидеть фактическую текущую позицию
→ различить / выбрать направление
→ сделать следующий доступный ход
→ получить ответ реальности
→ оказаться в новой фактической позиции
→ снова увидеть
→ повторить цикл
```

- ключевой предохранитель: `сложность оправдана только тогда, когда добавляет practically useful distinction, которое нельзя сохранить проще`;
- решение владельца: довести текущую архитектуру до финала, затем провести Whole-System Review, а не перестраивать весь канон после каждого нового инсайта;
- материал использован как приоритетная рабочая опора SP-S4-P05, но каноном P05 является отдельный утверждённый full theory / canonical слой.

- `zero-delta` и stage-boundary revision остаются допустимыми.

## Использование источников

```text
source material
→ архитектурная гипотеза
→ Architect pass
→ Reality Check / counterevidence
→ Red Team / falsification
→ явное решение владельца
→ full theory + canonical + delta
```

Исходный материал не получает статус доказательства только потому, что он личный, убедительный или согласуется с книгами.

### Сквозные границы

```text
телесный сигнал
= данные текущей позиции
≠ приказ
≠ доказательство истинности интерпретации

направление
≠ конкретный ход
```

### SP-S4-P06

Утверждённая короткая формула:

> **Сформированная способность ≠ гарантированная доступность.**

### SP-S4-P07

Рефлексия завершена; содержательный тезис ещё не утверждён.

Рабочая проверка:

```text
результат для меня важен
≠
от результата зависит,
могу ли я быть в порядке сейчас
```
