## SP-SRC-018 — сквозная формула

> **Selection Point — не технология получения желаемой реальности, а технология участия в создании собственной траектории внутри реальности, которую человек не контролирует полностью.**

```text
влияние ≠ контроль
участие в причинности ≠ единственная причина
создание траектории ≠ предопределение результата
```

## SP-SRC-019 — активный источник P10

Рабочая граница:

> **Устойчивость траектории ≠ неизменность её формы.**

```text
сохранить траекторию
≠
сохранить прежний план / темп / роль / масштаб
```

Внешние области: regulatory flexibility, coping flexibility, dynamic resilience, persistence vs goal disengagement/reengagement.
