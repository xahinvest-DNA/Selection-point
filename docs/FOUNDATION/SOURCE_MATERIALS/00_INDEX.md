## SP-SRC-018 — сквозная формула

> **Selection Point — не технология получения желаемой реальности, а технология участия в создании собственной траектории внутри реальности, которую человек не контролирует полностью.**

```text
влияние ≠ контроль
участие в причинности ≠ единственная причина
создание траектории ≠ предопределение результата
```

## SP-SRC-020 — рабочая метафора

> **Вес — показатель состояния системы. Похудение — возможный манёвр. Здоровье — направление. Способность управлять собой во времени — навык.**

> **Хороший водитель не контролирует дорогу. Он ведёт машину через меняющуюся реальность.**

## SP-SRC-021 — применение

Источник использован при утверждении SP-S4-P11.

Утверждённая формула:

> **Тренировать цикл выбора под нагрузкой, а не отдельную технику снятия нагрузки.**

```text
«панель» = достаточная reorientation
≠ тотальный self-monitoring

нагрузка = training condition
≠ цель / мера зрелости

state regulation
≠ choice recovery

visualization may help
≠ sufficient reality-coupled verification
```

Канонический P11 хранится в `../CANONICAL/40_STAGE_4_P11_CANONICAL.md`.

## SP-SRC-022 — текущая рабочая граница

Источник принят владельцем как рабочая опора и открыл SP-S4-P12 для архитектурного цикла.

Предварительная формула:

> **Переход не требует отсутствия выпадений. Способность должна иногда сохраняться непосредственно внутри значимой нагрузки, а после выпадения — становиться повторяемо восстанавливаемой из изменившейся фактической позиции.**

Граница S4 → S5:

```text
S4 = сохранять / восстанавливать участие внутри нагрузки
S5 = изменять систему условий, формирующую вероятные будущие позиции
```

Это рабочий источник, а не утверждённый P12.

## SP-SRC-023 — уточнение системной границы

> **Усилие действия ≠ усилие компенсации структуры.**

Рабочая гипотеза для будущей S5:

> **Не тратить основную силу на постоянную компенсацию собственной системы; перестраивать систему так, чтобы усилие всё больше направлялось на создание результата.**

Это уточнение не является утверждённой архитектурой S5 и используется только как source material при разработке P12 и последующих параметров.
