## Утверждённый результат SP-S4-P10

> **Устойчивость траектории ≠ неизменность её формы.**

Полный смысл:

> **Под значимой нагрузкой собственная жизненная линия может менять форму: план, темп, масштаб, роли, обязательства и отдельные цели. Признаком S4 является не сохранение прежнего устройства жизни, а способность снова организовывать последовательность доступных ходов из новой фактической позиции, сохраняя связь с релевантным направлением и право обратной связи изменить дальнейшее продолжение.**

## Обязательные предохранители

```text
сохранение формы ≠ сохранение траектории
изменение формы ≠ потеря траектории
сохранение направления ≠ persistence любой ценой
благоприятный исход ≠ зрелость
скорость восстановления ≠ зрелость
частая смена планов ≠ гибкость
```

Релевантные факты могут изменить конкретную цель и при необходимости само направление.

## Prospective observability

P10 не должен определяться только после результата. Наблюдаемый минимум до результата:

```text
признана новая фактическая позиция
→ прежний план не имеет автоматического приоритета
→ релевантный приоритет различим / пересмотрен
→ следующий ход выполним
→ feedback сохраняет право изменить продолжение
```
