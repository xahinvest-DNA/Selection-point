# 2. Источники Ступени 3

## SP-SRC-001

«Как мысль становится материальной» остаётся приоритетным первичным источником.

```text
мысль
→ внимание
→ воспринятая модель
→ состояние
→ поле выбора
→ действие / бездействие
→ ответ среды
→ последствия
→ следующая позиция
```

## SP-SRC-002

«Польза выбранной задачи и проверка реальностью» — приоритетный рабочий источник, применённый при утверждении SP-S3-P08.

Ключевые различения:

```text
осознанно выбрано ≠ полезно
созидание ≠ улучшение
авторство ≠ мудрость
сознательно принятая задача ≠ подтверждённо полезная задача
```

# 3. Активная Ступень 3

**Название:** «Формирование внутренней задачи и устойчивой практики».

Утверждены SP-S3-P01–SP-S3-P08.

## SP-S3-P01

> **Мне уже не обязательно жить из прежнего сценария — но я ещё не знаю, что будет организовывать мои действия вместо него.**

## SP-S3-P02

> **Факт обязателен к учёту, но не диктует единственное продолжение.**

## SP-S3-P03

> **Я не выбирал всё, из чего сформировался, но участвую в том, что формируется дальше.**

## SP-S3-P04

> **Я могу выбирать не только действие — я начинаю участвовать в выборе задачи, относительно которой действую.**

## SP-S3-P05

> **Я могу выбрать, для чего будет сделан следующий ход.**

## SP-S3-P06

> **Я выбрал задачу — значит теперь я действую из неё.**

Коррекция:

```text
задача сознательно выбрана
≠ задача получила устойчивый управляющий приоритет
```

## SP-S3-P07

> **Я действительно выбрал — и всё равно не могу на себя опереться.**

> **Неустойчивость выбора не доказывает его нереальность; она показывает, что выбранная линия ещё формируется.**

## SP-S3-P08 — Следующий навык

**Рабочее название:** «Сохранять без упрямства, менять без бегства».

Центральный тезис:

> **Следующий навык третьей ступени состоит в способности вести сознательно выбранную внутреннюю задачу через повторяющиеся циклы действия и обратной связи: сохранять или восстанавливать её управляющее присутствие, когда основания задачи сохраняются, и уточнять или менять её, когда фактическая следующая позиция даёт существенные основания для пересмотра.**

Короткая формула:

> **Сохранять без упрямства, менять без бегства.**

Формула опоры на себя:

> **Опора на себя — не гарантия, что я не изменю своё решение. Это способность снова участвовать в том, сохранить его или изменить.**

Три объекта возможной корректировки:

```text
1. управляющее присутствие задачи
2. способ решения задачи
3. сама задача
```

Уточнение устойчивости:

> **Устойчивость — способность сохранять выбранную организацию достаточно долго, чтобы получить реальную обратную связь, и одновременно оставаться способным изменить её, когда накопленные данные дают основания для пересмотра.**

Ключевые границы:

```text
негативный результат одного цикла
≠ автоматическое опровержение задачи

положительный результат одного цикла
≠ доказательство полезности задачи

обратная связь
= данные для следующего выбора
≠ внешний приказ
```

P08 не вводит нового общего термина, риска или визуальной модели.

Пространство 2 не доказывает полезность выбранной задачи и не гарантирует внешний результат.

# 5. Доказательный и безопасностный статус

SP-S3-P08 является утверждённым положением внутренней архитектуры Selection Point, а не научно доказанной самостоятельной интервенцией.

Требуется обзор goal adjustment, goal disengagement/reengagement, adaptive persistence, psychological flexibility, self-regulation, feedback processing, error-based learning, sunk cost/escalation of commitment, decision-making under uncertainty и смежных направлений.

Особые границы:

- сознательно выбранная задача не считается автоматически полезной;
- один успех или неуспех не является окончательным вердиктом;
- устойчивость не равна неизменности решения;
- нельзя защищать разрушительную линию словом «последовательность»;
- нельзя менять задачу при первом дискомфорте и называть это гибкостью;
- AI, ведущий или метод не определяет человеку универсально «правильную» задачу;
- обратная связь является данными для выбора, а не внешним приказом;
- P08 не заменяет медицинскую, психотерапевтическую или кризисную помощь.
