## 3. Последняя содержательная точка — SP-S4-P02

Главная формула:

> **Под нагрузкой особенно важно не только что я вижу, но и что сейчас определяет, чему я придаю значение.**

Ключевое различение:

```text
функциональное сужение
≠ искажённое сужение
```

Формула доверия:

> **Доверие опыту — не цель. Цель — сохранить доверие реальности даже тогда, когда опыт требует быстрого ответа.**

Граница внутренней задачи:

```text
внутренняя задача организует внимание
≠ внутренняя задача определяет истину
```

P02 не противопоставляет интуицию рациональности. Критерий — возможность фактической текущей позиции корректировать рабочую модель.

## 4. Новая архитектура управления

С 28 августа 2026 года действует governance v4.0.

### Единственный источник текущего статуса

`PROJECT_STATE.yaml`.

README, этот файл, `docs/CURRENT_STATE.md`, индексы и Codex README являются производными представлениями и не должны самостоятельно хранить другую остановку.

### Continuous Reality Check

Фаза 3 теперь имеет постоянный параллельный контур:

```text
архитектурная гипотеза
↕
наблюдаемость
альтернативные объяснения
контрпримеры
внешние данные
условия опровержения
```

Это не ранний пилот курса.

### Red Team / Falsification

Перед утверждением каждого нового архитектурного параметра обязателен отдельный pass, который пытается разрушить предлагаемую модель.

### Delta-first

После каждого параметра создаётся локальная библиотечная delta. Большие реестры консолидируются после P05, P10, P13, на границе ступени либо по отдельному решению Андрея.

### Матрица 5 × 13

Она остаётся действующим исследовательским каркасом, но не считается законом реальности. Допускаются самостоятельная дельта, `zero-delta` или явный пересмотр структуры.
