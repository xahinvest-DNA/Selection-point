## 2. Рабочий результат SP-S4-P10

Центральная граница:

> **Устойчивость траектории ≠ неизменность её формы.**

Рабочий тезис:

> **Под значимой нагрузкой могут измениться план, темп, масштаб, распределение ресурсов, роли, обязательства и отдельные цели. Жизненная зрелость S4 не требует сохранить прежнюю форму; она проявляется в способности снова организовывать последующие ходы из изменившейся фактической позиции относительно релевантного направления и обратной связи.**

Дополнительная формула:

> **Новая фактическая позиция может требовать новой формы продолжения.**

## 4. Red Team boundaries

```text
сохранение направления
≠ persistence любой ценой

изменение формы
≠ зрелость само по себе

хороший внешний исход
≠ критерий P10

быстрое восстановление
≠ критерий P10

объективно тяжёлая позиция
≠ потеря выбора
```

Реальность сохраняет право изменить не только форму, но при релевантных фактах и конкретную цель / само направление.

## 5. Защита от ретроспективного рассказа

До знания итогового результата должно быть возможно различить:

1. изменившуюся фактическую позицию;
2. отсутствие автоматического приоритета прежнего плана;
3. релевантный приоритет либо его осознанный пересмотр;
4. practically available следующий ход;
5. открытость дальнейшей коррекции по feedback.
