## 2. Утверждённый SP-S4-P12

4 сентября 2026 года после обязательных трёх вопросов, Williams / Millman / Fritz synthesis, Architect pass, RC-016 и Red Team Андрей явно утвердил P12 решением:

> **«Утверждаем».**

Центральная формула:

> **Не непрерывный контроль, а достаточно надёжное сохранение и функциональное возвращение выбора под релевантной нагрузкой.**

Ключевое различение:

> **Re-entry должен изменить ещё доступное продолжение.**

Утверждённый двухкомпонентный профиль:

```text
сохранение функционального доступа
+
functional re-entry после снижения доступности
```

## 3. Главные границы

```text
безошибочность не требуется
спокойствие ≠ освоение
universal stress resilience не утверждается
late understanding ≠ functional re-entry
natural recovery ≠ own recovery operation
one rehearsed stressor ≠ sufficient transfer
support scaffold ≠ external operator of choice
хороший исход ≠ P12
recovery speed ≠ maturity criterion
```

Критерий доменно / контекстно релевантен: перенос на новые виды нагрузки не считается автоматическим.

## 4. Граница S4 → S5

```text
S4:
надёжность сохранения / восстановления участия
внутри релевантной нагрузки

S5:
системный уровень условий,
формирующих вероятные будущие позиции,
становится следующей central task
```

> **Не бесконечно лучше возвращаться из одних и тех же условий, а начать видеть условия, которые регулярно делают возвращение необходимым.**

SP-SRC-023 сохраняет дополнительное рабочее различение:

> **Усилие действия ≠ усилие компенсации структуры.**

Это source material для будущей S5 и не предопределяет её полную архитектуру.
