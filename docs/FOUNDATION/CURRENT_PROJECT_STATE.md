## 3. Главное исправление после повторного анализа

Отвергнута слишком пассивная формула:

```text
тело = только индикатор / данные состояния
```

Сохранена более точная системная граница:

```text
тело
=
часть текущей позиции
+
может быть причинным участником дальнейшей динамики состояния
```

При этом:

```text
body-state bidirectionality
≠ unique S4 mechanism
```

Двусторонность является сквозным свойством системы и частично уже содержится в HCM-02, S1-P09 и S3-P09.

---

## 4. Обязательные предохранители

```text
телесный сигнал = данные
≠ только данные

изменение тела может влиять на состояние
≠ гарантирует изменение состояния

улучшение состояния
≠ восстановление выбора

сильная активация
≠ потеря выбора

спокойствие
≠ доказательство выбора

телесный показатель
≠ универсальный биомаркер выбора
```
