## 3. Что изменил повторный анализ P09

Первый анализ верно установил:

```text
напряжение ≠ потеря выбора
спокойствие ≠ наличие выбора
```

Но он недостаточно явно учитывал активную причинную роль тела.

Контрпример владельца:

```text
приятная новость / внутренний смысл
→ меняется состояние
→ меняются мимика, поза, движения
```

и обратно:

```text
намеренная улыбка / изменение позы, дыхания, движения
или внутреннего образа
→ может измениться внутреннее состояние
```

Внешний обзор по facial feedback, posture, respiration и mental imagery подтверждает ограниченную причинную двусторонность: телесная / перцептивная конфигурация может влиять на affect и cognition, но эффекты неодинаковы, контекстны и не являются универсальной кнопкой.

Рабочее исправление:

```text
тело
= часть текущей позиции
+
может быть одним из причинных участников её изменения
≠
только индикатор
≠
универсальный управляющий рычаг
```

## 4. Почему рекомендация `zero-delta` сохранилась

Повторный Architect / Red Team test отделил два вопроса.

### Общий механизм человека

```text
состояние ↔ тело
```

Двусторонность не начинается на четвёртой ступени. Она является сквозным свойством системы и частично уже содержится в HCM-02, S1-P09 и S3-P09.

### Специфическая дельта S4-P09

После вычитания уже утверждённых положений отдельная новая телесная структура S4 по-прежнему не обнаружена.

```text
S3-P09:
телесное состояние влияет на доступность,
но не определяет обязательный ход

S4-P01:
сформированная способность меняет доступность под нагрузкой

S4-P08:
участие может восстановиться до полной нормализации состояния
```

Новая двусторонность не создаёт четвёртого stage-specific механизма.

## 5. Граница P09 / P11

Если формула становится такой:

```text
намеренно изменить мимику / позу / дыхание / движение
→ попытаться изменить состояние / доступность участия
```

это уже не описание «телесного проявления» P09, а **функциональный класс практического действия**.

Он сохраняется как сильный кандидат для SP-S4-P11 и будущей Фазы 5.

Но нельзя заранее канонизировать:

- улыбку;
- конкретную позу;
- дыхательный паттерн;
- visualization;
- любой другой телесный вход

как универсальный способ восстановления выбора.

## 6. Текущая рекомендация

> **SP-S4-P09 — amended `zero-delta`.**

Рабочая формулировка:

> **Отдельная новая телесная структура четвёртой ступени не подтверждена. При этом тело нельзя считать только отражением или индикатором внутреннего состояния: телесная организация является участником двустороннего причинного контура и в некоторых условиях её изменение способно изменять эмоциональное, когнитивное и функциональное состояние. Этот механизм является сквозным, а не специфичным для S4; намеренное использование телесного входа относится прежде всего к будущему функциональному профилю P11.**

Коротко:

> **Тело не только показывает позицию — оно участвует в её изменении. Но это не отдельная S4-дельта.**

Обязательные предохранители:

```text
body change can influence state
≠ guarantees state change
```

```text
state improvement
≠ choice restored
```

```text
body-state bidirectionality
≠ unique S4 mechanism
```

Это **не утверждённый результат** до явного решения владельца.
