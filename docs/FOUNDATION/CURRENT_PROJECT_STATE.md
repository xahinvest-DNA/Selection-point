# 2. Источники Ступени 3

## SP-SRC-001

«Как мысль становится материальной» остаётся приоритетным первичным источником.

## SP-SRC-002

«Польза выбранной задачи и проверка реальностью» — приоритетный рабочий источник, применённый при утверждении SP-S3-P08.

```text
осознанно выбрано ≠ полезно
созидание ≠ улучшение
авторство ≠ мудрость
```

## SP-SRC-003

«Телесные сигналы и формирование навыка» — приоритетный рабочий источник, применённый при утверждении SP-S3-P09.

```text
сознательно выбранная задача
≠ уже перестроенная
телесно-поведенческая организация
```

## SP-SRC-004

«Создание, выбранное направление и неизвестная позиция» — приоритетный рабочий источник, применённый при утверждении SP-S3-P10.

Ключевые различения:

```text
решение проблемы ≠ создание
не знать конечный пункт ≠ не иметь выбранного направления
направление без движения ≠ создаваемая траектория
бездействие ≠ сохранение неизменной позиции
```

Главная рабочая формула:

> **Следующая позиция возникнет в любом случае. Вопрос не в том, будет ли она сформирована, а в том, насколько человек участвовал в направлении её формирования.**

# 3. Активная Ступень 3

**Название:** «Формирование внутренней задачи и устойчивой практики».

Утверждены SP-S3-P01–SP-S3-P10.

## SP-S3-P08 — Следующий навык

> **Сохранять без упрямства, менять без бегства.**

> **Опора на себя — не гарантия, что я не изменю своё решение. Это способность снова участвовать в том, сохранить его или изменить.**

Три объекта возможной корректировки:

```text
1. управляющее присутствие задачи
2. способ решения задачи
3. сама задача
```

## SP-S3-P09 — Телесные проявления

**Рабочее название:** «Тело между прежней и формирующейся организацией».

Главная формула:

> **Меняется не обязательно то, что я чувствую; меняется то, что мне доступно внутри этого состояния.**

Дополнительная формула:

> **Старая реакция может ещё оставаться, пока новое продолжение уже становится доступным.**

Ключевая граница:

```text
старая телесная реакция
≠ старая обязательная траектория
```

## SP-S3-P10 — Жизненные проявления

**Рабочее название:** «Собственная линия начинает оставлять след в устройстве жизни».

Центральный тезис:

> **Жизненные проявления третьей ступени состоят в том, что сознательно выбранная внутренняя задача начинает оставлять фактический след в последовательности жизненных ходов и следующих позиций. Человек всё яснее различает связь между собственной внутренней организацией, действием или бездействием, независимым ответом среды и фактической следующей жизненной позицией и начинает сознательно участвовать в повторяющемся изменении этой траектории. Признаком третьей ступени является не внешняя успешность и не исчезновение прежних последствий, а изменение способа продолжать жизнь из существующей позиции.**

Главная формула:

> **Я начинаю последовательно участвовать в том, какую позицию формирую дальше.**

Дополнительная формула:

> **Меняется не обязательно вся моя жизнь сразу; меняется то, каким способом я продолжаю её создавать из существующей позиции.**

Дельта:

```text
SP-S1-P10:
текущая жизнь как накопленная позиция

SP-S2-P10:
повторяющаяся функциональная позиция
в нескольких жизненных циклах

SP-S3-P10:
выбранная задача начинает оставлять
фактический след в последовательности
жизненных ходов и следующих позиций
```

Ключевые различения:

```text
понимать причинность
≠ изменять траекторию

внутренняя организация влияет на участие
≠ создаёт все внешние события

старое внешнее положение
≠ старый способ его продолжать

внешняя успешность
≠ критерий ступени

не знать конечный пункт
≠ не иметь выбранного направления
```

P10 не требует конкретной долгосрочной точки Б, не объявляет постоянную активность благом и не превращает бездействие в автоматическую ошибку.

# 4. Визуальные модели

SP-VM-01 и SP-VM-02 связаны с архитектурой до P10 включительно.

Для P10:

```text
текущая позиция
+ выбранная задача / направление
→ доступный ход
→ независимый ответ среды
→ фактическая следующая позиция
→ новый цикл
```

SP-VM-01 показывает последовательность ходов как формирующуюся траекторию.

SP-VM-02 сохраняет различение между текущим фактом, представленным направлением и фактически возникшей следующей позицией.

Новая визуальная модель для P10 не вводилась.

# 5. Доказательный и безопасностный статус

SP-S3-P10 является утверждённым положением внутренней архитектуры Selection Point, а не доказанной универсальной психологической теорией.

Требуется обзор agency, perceived agency, self-regulation, goal-directed behavior, goal pursuit and adjustment, implementation intentions, habit formation, behavioral consistency, self-efficacy, feedback learning, reciprocal determinism, ecological/transactional models, person–environment interaction, path dependence, behavioral maintenance, relapse/lapse, resource allocation и psychological flexibility.

Особые границы:

- человек не объявляется причиной всех внешних событий;
- ответственность относится только к доступной части участия и не равна вине;
- внешняя успешность не является критерием ступени;
- сохранение прежних последствий не доказывает отсутствие изменения;
- отдых, пауза, отказ и бездействие могут быть сознательными ходами;
- отсутствие конкретной конечной цели не означает отсутствие направления;
- выбранная задача не гарантирует результата и не считается автоматически полезной;
- AI или ведущий не вправе назначать человеку правильное направление жизни.
