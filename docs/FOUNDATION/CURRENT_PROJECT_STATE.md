## 3. Почему выбран zero-delta

Проверенные кандидаты не дали самостоятельной practically useful delta:

```text
чрезмерная важность
→ в основном P02 / рамка восприятия

разрушенные ожидания
→ в основном P06 / разрушение гарантии

«я буду счастлив, когда...»
→ возможная тема границы S4→S5

социальное непонимание
→ контекстная, не универсальная боль

боль утраты значимого будущего
→ общечеловеческая, не S4-specific
```

Матрица 5×13 не заполняется искусственно.
