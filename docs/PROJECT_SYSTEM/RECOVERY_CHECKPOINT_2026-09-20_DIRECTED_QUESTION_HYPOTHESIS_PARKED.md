## Binding boundaries

```text
question may guide search
≠ question establishes truth

presuppositional question
may bias attention / memory / report

changed report
≠ changed realization

question exposure
may be intervention / scaffold
≠ Stage 1 proof

reality must retain the right
to contradict the premise and expected answer
```

The rule `question > affirmation` is not treated as established. The research literature is mixed for interrogative-vs-declarative self-talk, while broader question-behavior literature supports only a small and heterogeneous measurement-reactivity effect.
