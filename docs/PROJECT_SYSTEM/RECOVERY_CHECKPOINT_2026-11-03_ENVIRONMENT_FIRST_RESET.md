V0 is intentionally limited to:
- one target capability;
- 10–15 representative situations;
- one observable domain: effective body / physical efficiency;
- at least one multi-scale trajectory consequence;
- one real-world transfer experiment;
- manual/simple delivery allowed.

No VR, AI, app or complete curriculum is required to test the core mechanism.
