## 2. Owner clarification on 17 September 2026

The target is not to escape automaticity.

Long-term direction:

> useful decisions/actions should become sufficiently trained that they can occur with low deliberative load in relevant conditions.

At the same time, the project must seriously study how an established automatic continuation can be interrupted/reopened when it is destructive or no longer fits current reality/direction.

Observed problem class:

```text
strong intention
→ later cue/state/context
→ old automatic continuation reappears
```

This must not be reduced to weak will or insincere intention.

## 4. Current research synthesis

Supported working distinctions:

```text
intention ≠ realization
interruption ≠ new automaticity
old learning may remain retrievable
repetition in stable cue/context can increase automaticity
robust transfer requires later context/state variation
```

Proposed design hypothesis:

```text
old automatic continuation
→ relevant mismatch / critical cue
→ selective interruption window
→ executable alternative
→ realization
→ consequence / feedback
→ repetition
→ increasingly effective automaticity
```

Red Team refinement:

> The target is selective interruptibility, not permanent conscious control.

A mature candidate architecture may include both:

```text
useful automatic default
+
rapid re-entry when meaningful mismatch appears
```

This is not yet canon.
