## 1. Trigger

During Gate C Owner review, the Owner proposed that searching for hidden causes is not the core capability Selection Point should train.

Key concern:

> Deep retrospective explanations can become an end in themselves and shift attention away from what is occurring now and what can still be changed next.

Owner provided an illustration of people skilled in hidden-needs / childhood-origin / mechanism analysis whose relevant life patterns appeared unchanged years later. The illustration is retained as a warning, not empirical proof.

## 2. Current methodological candidate

Training-layer center:

```text
relevant current position
→ notice enough
→ distinguish what matters
→ identify what is already realized vs the relevant open edge
→ choose relative to reality + relevant local direction
→ actually realize
→ observe consequence / updated position
```

No hidden psychological cause is required.

## 3. Meaning of present-centered

Present-centered does not mean history-blind.

The current position may include:

- relevant external facts;
- current internal events;
- already-realized actions;
- existing consequences;
- resources / constraints / support;
- commitments and responsibilities;
- relevant local task/direction;
- known recent history when it materially changes the next move.

The current position is selective, not exhaustive.

## 4. Cause boundary

Allowed:

- known/testable causal information;
- observed relations useful for changing conditions;
- consequences of prior action.

Not required:

- root-cause discovery;
- childhood-origin explanation;
- hidden need;
- unconscious intention;
- identity-protection explanation;
- inferred trauma mechanism.

Core distinction:

```text
known/testable causal information
≠ speculative hidden psychological origin
```

## 7. Binding safeguards

- `now` may not erase accumulated consequences or accountability;
- arbitrary action is not participation: the next move requires a relevant local direction/task/responsibility anchor;
- present awareness is an entry operation, not completion;
- introspection volume is not capability;
- action is not mandatory: conscious non-action, waiting, repair and help-seeking can be valid continuations;
- RC-018 remains binding: selected ≠ realized ≠ consequence ≠ used feedback;
- AI/coach cannot assign hidden cause as fact or perform the substantive noticing/choice for the participant.
