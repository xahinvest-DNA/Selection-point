## 1. Decision

The Owner approved Stage 1 Gate D — Learning Units.

Approved learner-facing architecture:

```text
NOTICE
→ OPEN
→ REALIZE
→ UPDATE
```

Compact candidate wording:

> **Заметь → открой → сделай → сверься с реальностью.**

The approved artifact is `SP-TR-S1-LU-001`.

## 2. Binding meaning of the four units

### LU-1 — NOTICE
Notice enough of the relevant current position for the next continuation to become distinguishable.

### LU-2 — OPEN
Create or recognize a small interruption window so that a misaligned automatic continuation is no longer the only active route.

### LU-3 — REALIZE
Choose one reality-anchored, actually executable continuation and realize it.

### LU-4 — UPDATE
Observe what actually happened and update the current position without treating one consequence as universal causal proof.

## 3. Cross-cycle automaticity direction

Approved distinction:

```text
one Stage 1 cycle
≠
new automaticity
```

Re-automatization belongs to the cross-cycle learning direction:

```text
repeated useful SP cycles
→ easier retrieval / lower cognitive load
→ possible useful automatic default
+
selective interruptibility under meaningful mismatch
```

No fixed repetition count, duration or mastery threshold is approved.

## 4. Binding boundaries

Gate E must preserve:

1. automaticity is neutral; less automaticity is not automatically better;
2. noticing ≠ interruption;
3. intention ≠ realization;
4. interruption ≠ replacement;
5. selected continuation ≠ realized continuation ≠ consequence ≠ used feedback;
6. interruption is selective and requires a relevant mismatch;
7. local operational anchor is sufficient; final life-direction certainty is not required;
8. late entry after the main action remains valid;
9. old learning may remain retrievable;
10. one successful cycle does not prove re-automatization;
11. useful automated replacement is not by itself proof that a conscious Stage 1 Selection Point occurred in that episode;
12. prompt/questionnaire/scaffold provenance must remain visible;
13. questionnaire data remains telemetry even when questionnaire exposure functions as intervention;
14. prompted performance must not be mislabeled independent capacity;
15. professional/external support may itself be the available participation;
16. robust high-load transfer is not minimum Stage 1 competence.
