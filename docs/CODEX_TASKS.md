## Почему очередь приостановлена

Текущая работа является методологической архитектурой. Codex не должен самостоятельно:

- открывать следующий параметр;
- дописывать метод;
- определять параметры ступеней;
- выполнять Reality Check вместо методологического обсуждения;
- принимать решение `zero-delta`;
- проектировать модули курса;
- определять количество уроков;
- выбирать формат первой версии;
- создавать приложение;
- выбирать технический стек.
